# Task 7C：斜めの道と区画生成

2026-10-28。2026-10-27の「横長い道と真上へ跳ぶ道が多いので、横と縦の移動を混ぜたい」という依頼への実装。7A・チュートリアル5/11修正・7Bの未コミット変更を引き継ぐ。検証の完了状況は後述。

## 実装

- **段床通路**：左右に離れ、高さの違う空洞・入口を20〜50度で接続する。段は32〜64px、床幅64〜128px、天井は床から224〜256px。床幅と段差を乱数で変え、同じ高さが続く踊り場は256px以下にする。
- **斜めの足場列**：256px幅の着地面を横64〜192px、縦96〜160pxずつずらす。岩の支持面と、開口に延びる薄い足場を組み合わせる。天井は各着地面の256px上、全体の角度20〜50度、高低差768px以下。上側の空洞の床が途中で切れる口は薄い足場でつなぐ。
- 空洞の追加候補を左右4：上下1にし、左右候補の90%で、間隔に対して0.5〜0.7倍の高低差を付ける。空洞の寸法・開始位置・ボス用空洞・岩の間隔は従来どおり。斜め接続を優先して木と0〜3本の追加辺を選ぶ。
- 接続先以外の空洞を横切る候補と、共通の空洞の外で他の接続と交差する候補は棄却する。形状・支持面・保護範囲の検証を追加した。既存の通常／最大掘削後の全支持面の強連結、全ゲート、敵・ブロック・収集物・能力の寄り道の検証は維持する。
- 内装を繰り返しても成立しない骨組みを先に除外し、必要な内装の割合とブロック4個を満たさない候補は重い到達グラフの構築前に選び直す。足場の余白の判定では、空洞の外へ延びた足場も床の段差から保護する。
- ゲートの決定関数・3試行後のフォールバック・生成の順番からの独立性・読み込みと状態保持・原点移動・戦闘の規則は変更しない。

## 集計方法

シード0〜199について、各`(0,0),(1,0),(-1,1),(0,-1),(2,2)`の同じ1000区画を前後で生成し、独立にvalidateする。シード・区画座標・集計関数は共通。内部の接続名だけで数えず、既存の通路でも、単調な段床・高低差96px以上・角度20〜50度に当たるものを斜めに含める。斜めの足場列を加え、高低差のある全接続を分母とする。

平らな横通路の長さは、`tunnels`の連続する同じ床高の矩形を合算する。境界の短い横通路も含め、空洞の床は含めない。縦穴は`shafts`の実体数を数え、ゲート用を別記する。フォールバックは別に数える。時間は`generate`全体で、外部のvalidateは含めない。
