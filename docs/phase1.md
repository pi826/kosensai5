# 第1段階：整数HP・操作・キー設定

2026-10-16。全体の予定は `roadmap_v2.md` を参照。

これは第1段階時点の記録です。現在のマップと検証は `phase2.md` を参照してください。下記の試験スクリプトは現在、第2段階向けに更新されています。

## 実装内容

- HPを100の整数ゲージに変更。通常の敵弾は12、誘導弾は18ダメージ。同色吸収ではHPは減らず、1秒間の被弾後保護を維持する。
- 敵頭上とボスHUDのHPは残量の整数だけを表示。与えた実ダメージを黄色の数字で0.8秒浮かせる。吸収・無敵中には表示せず、致死時も敵と独立した表示を残す。
- 地上は6フレームで最大速度、3フレームで停止。空中で入力を離すと2フレーム以内に横速度が0になる。
- 長押しジャンプは実物理で約170px、最短押下は約43px。長押しの滞空は約0.53秒、短押しは約0.27秒。
- 着地直前の入力を0.12秒予約し、足場を離れた直後は0.1秒ジャンプできる。予約中にキーを離した場合も短押しの意図を保持する。
- 天井の角に少し引っかかった場合は左右約6pxの範囲で補正する。中央の天井や隣の壁を通過しない。衝突形状の余白は補正距離に別途加える。
- 表示だけをジャンプ時に伸ばし、着地時につぶして土埃を出す。衝突形状は固定。
- タイトル・一時停止・結果画面に「キー設定」を追加。左右移動、ジャンプ、射撃、色切り替え、誘導弾、一時停止を各2キーまで設定する。
- 設定は `.userdata/Godot/app_userdata/CHROMA SHIFT/controls.cfg` に保存。案内表示も変更後のキーに切り替わる。
- 設定中のキーはゲームへ漏らさない。競合、最後のキーの削除、不正な設定ファイルを検査する。保存できない場合は画面に理由を出し、現在の起動中の変更は維持する。
