# 第2版の段階実装計画

作成日: 2026-10-16。各段階を遊べる状態で区切り、操作・構造・敵・成長・素材を順に検証する。

## 決まった方向

- 2026-10-26のユーザー決定（Task 6A）: 能力の宝箱は二段ジャンプ・空中ダッシュ・滑空の3つ。倒れて再挑戦すると通貨・鍵・能力・開封と収集、6Bの装備も全てリセットする。第4段階を6A（通貨・鍵と宝箱・能力）と6B（商人・装備・回復薬）に分ける。6Aの記録は `task6a_keys_abilities.md`。

- 2026-10-25のユーザー決定（Task 5E）: チュートリアルはタイトルから選ぶ別ステージにする。本編の無限洞窟とは別の固定された一続きの地形で、現在のキー設定を使って基本操作・色と吸収・誘導弾・回復を順番に練習する。完了後はタイトルへ戻れ、本編開始も選べる。本編の状態を汚さない。2026-10-26の実装・検証は `task5e_tutorial.md`。
- 2026-10-25のユーザー決定（Task 5D）: ガーディアン3体を空洞内で積極的に動かす。3体撃破でランダムな別区画にラスボスを出し、地域名・方角・距離を通知する。ラスボス撃破で別の場所にガーディアン3体を復活させ、この循環でラスボスを3回倒すと裏ボスを出す。全ボスが移動し、裏ボス撃破でクリア、結果にスコアと時間を表示する。3体だけでクリアする旧ルールを置き換える。2026-10-26の実装・検証は `task5d_bosses.md`。チュートリアルは5Eで別途実装。
- 2026-10-25のユーザー決定（Task 5C）: 誘導弾は発射回数を最大5回まで貯め、1回消費して複数の敵へ一斉発射する。通常敵の撃破で1回分、ガーディアンで2回分、同色吸収も一定数で1回分。ハートと箱の破壊でHPを回復する。通常敵・箱・ハートは一定時間後、視界外で確率的に復活し、区画の解放中も経過時間を扱う。2026-10-26の実装・検証は `task5c_rewards.md`。
- 2026-10-25のユーザー決定（Task 5B）: マップの大きさに制限を設けず、探索に応じて上下左右へ洞窟を生成し続ける。一続きの地形を維持し、区画の継ぎ目・読み込み・ワープを見せない。5B-1は区画データと検証のみ（`task5b_sectors.md`）、読み込み・解放・地図・カメラ・HUDへの組み込みは5B-2で行う。2026-10-26に組み込み、検証結果を `task5b_streaming.md` に記録。
- 2026-10-25のユーザー決定（Task 5A）: 地図の見出し・凡例・撃破数の文字を消して地図を広げ、画面表示を日本語化する。射撃方向は「前 / 上 / 下」で表示し、内部の0° / 60° / -60°は維持する。高さをほぼ保ったままジャンプの滞空を約1.3倍にする。HP変化時に頭上の緑・赤・灰の3色バーと増減数値を表示し、回復分は明るい緑で示す。異色の通常敵・ガーディアンとの接触でダメージを受け、被弾後の無敵を1.5秒にする。実装・検証は `task5a_ui_feel.md`。
- 5A以降の予定: 5Bは大きさの制限のないマップ、5Cはハート・箱による回復と撃破報酬・敵などの復活、5Dは中ボスの移動とラスボス・裏ボス、5Eはチュートリアル。5Aではこれらを実装しない。

- 2026-10-25のユーザー決定（Task 4B）: 開けた空洞を通路と縦穴でつなぐ洞窟にする。射撃敵は接近するプレイヤーを見通せる場所に置き、地形を越える攻撃のbreaker・laserとflyerを多めにする。薄い足場が弾を止める仕様を保ち、通常敵を40体へ増やす。実装と検証は `task4b_caves.md`。

- 2026-10-25のユーザー決定（Task 4A）: 左手で移動、右手で射撃・色切替・角度切替・誘導弾を操作する。マウス照準は使わず、仰角を0° → 60° → -60°で循環する。薄い足場は下キーですり抜け、誘導弾は複数の敵をロックオンする。実装・検証は `task4a_controls.md`。次のTask 4Bで高低差のある洞窟地形に進む。今回は地形・敵の配置と数を変えない。
- 現在の最終目標は上記5Dの裏ボス撃破。第2段階時点の「中ボス3体でクリア」は過去の仕様。
- 第2段階での復帰は、同じマップを最初から。通常敵・中ボス・探索状況をすべて初期化する。戦闘込みの1ラン5〜10分は旧3体構成での目標で、5D構成の所要時間は未確認。
- マップは地形が一続きの単一ワールドとし、歩行・ジャンプで上下にも探索する。探索中にロード、部屋切り替え、移動キーでのワープを挟まない。3地域を背景で見分けられるようにし、探索済み地形のミニマップを用意する。
- 地形はグリッドに配置し、上下左右と斜めの8近傍からタイルを自動接続する。「8方向」は地形の接続を指す。
- 同色吸収・異色ダメージの基本は継続する。吸収は誘導弾ゲージをためる役割。
- **通貨は敵撃破で獲得する。装備購入などで強化し、独立した経験値レベルは作らない。** 吸収による通貨獲得は行わない。
- 2026-10-25のユーザー決定で、既存の通常敵3種類を残し、「弧を描くレーザー・地形破壊・地形設置・飛行」の4種類を追加する。通常敵は合計7種類とし、攻撃・移動・地形との関係で違いを作る。
- 鍵で錠付きの箱を開け、二段ジャンプを解放する。商人で回復アイテムや装備を買えるようにする。

## 1. 操作と基礎表示 — 実装・自動検証済み

- HP100の整数ゲージと現在値を表示。通常被弾12、誘導弾18を初期値とし、将来の回復や装備を扱える単位にする。
- 最高速度まで約6フレーム、停止約3フレームの地上操作。空中は強めに制動する。
- ジャンプを高くしつつ素早く着地する。短押しと長押し、0.1秒のコヨーテタイム、0.12秒の入力予約、小さな天井角の補正を実装する。
- ジャンプの伸び、着地のつぶれと土埃で動作を伝える。衝突形状は表示の伸縮で変えない。
- タイトルと一時停止からキー設定を開く。各操作2キー、変更の保存・再読込、重複の拒否、既定値への復帰、案内表示への反映を行う。
- 検証: HP・戦闘の回帰、実物理での操作補正、1,000シードの生成、3シードの走破、設定UIと保存。
- この段階では従来の横長マップとボス1体を使い、操作の変化を比較できるようにする。

## 2. 縦探索・3地域・3体撃破・ミニマップ — 実装・自動検証済み

- 横一列の区間から、地面の起伏・上段足場・縦の登攀路を持つ単一マップへ作り直す。初期グリッドは32px。初期サイズは12,288×3,072px。
- 左右の地域を連続した床で結び、中央の上段へは128px間隔の12段の足場で登れるようにする。タイルの選択は8近傍で扱う。
- 3地域に1体ずつ中ボスを置き、識別番号で撃破状態を記録。3体すべての撃破をクリア条件とする。
- カメラは小さな動きを吸収しながら上下左右へ追従する。速い落下では下を先に映し、着地先とプレイヤーが画面内に残るようにする。
- ミニマップに現在位置・探索済みの地形・現在の視界・発見した中ボスを表示する。未探索の地形を最初からすべて明かさない。
- 素材ができるまでは地域ごとの仮背景色を使い、後で画像を差し替える。
- 検証: シード再現、連続した床と上下の足場、全中ボスへの実歩行での往復、地域境界での状態保持、落下中のカメラ、3体撃破の順序と重複、ミニマップの一致。
- 死亡時の完全リセットと5〜10分の目標を継続する。所要時間・難易度は人の実プレイで調整する。
- 第2段階の仕様と検証の詳細は `seamless_world.md`。部屋方式だった時点の記録は `phase2.md`。第3段階の追加分は `phase3_enemies.md` に記録する。

## 3. 通常敵4種類の追加 — Task 1・2実装済み

2026-10-25のユーザー決定で元の5種類案を変更した。

- 既存の turret（固定砲台）・walker（地上巡回）・shifter（色切替）は残す。
- Task 1実装済み: flyer（飛行）・laser（弧を描くレーザー）。
- Task 2実装済み: breaker（地形破壊）・builder（地形設置）。通常敵は7種類。床の表面64px・壊れるブロック・一時的な壁を実行時に変更する。中央登攀路と地上中ボスを保護し、通常ジャンプでの往復を維持する。
- 元の案の「接近し、射撃時は距離を取る敵」「足場を跳び移る敵」は保留。walker・shifterの移動仕様の拡張も今回の変更には含めない。

- 同色吸収・異色ダメージは共通処理を使う。耐久力だけで役割を分けない。
- 地上敵の支持面、飛行敵の移動領域、壁や足場端での方向転換を生成データから決める。
- Task 1の検証: 1,000シードで両追加種を保証、飛行レーン、実弾による2発撃破、レーザーの予告・遮断・吸収・被弾・停止・消去、地域境界での状態保持。項目数と結果は `phase3_enemies.md`。
- Task 2の検証: 1,000シードの両追加種・ブロック配置・飛行敵の下の空間、実物理による穴・壁・砲弾、破壊後の往復、ミニマップ、境界保持と再挑戦。実行結果と爆発20回の処理時間は `phase3_enemies.md`。
- 異なる高さ・敵の組み合わせでの難易度と見やすさは、人の実プレイで確認する。

## 4. 鍵・箱・能力・商人・装備 — 6A実装、6Bは未実装

- 6A: 敵撃破の通貨「結晶」、鍵の取得と消費、能力3つの箱と結晶の箱、HUD・結果・地図への表示。個体と永続IDで撃破報酬の重複を防ぎ、復活した敵は再び報酬を与える。吸収による通貨・独立した経験値レベルは作らない。
- 能力の箱と最初の鍵は初期能力で往復できる場所へ置く。解禁後の寄り道は二段ジャンプ／二段ジャンプ＋空中ダッシュ／全能力の組で検証する。ボス・ゲートを含む主経路は初期能力のまま。
- 区画の解放・再読み込みと原点の移動では開封・収集・能力を維持する。死亡後の再挑戦では通貨・鍵・能力・開封・収集を全て初期化する。6Bの装備も同じルールにする。
- 検証: 撃破報酬・吸収・重複・復活、鍵取得→消費→開封、保持と再挑戦、能力の実物理・入力設定・実測、生成と能力別到達、実入力による開始→鍵→解禁→寄り道→帰還、通常描画。結果は `task6a_keys_abilities.md`。
- 6B（未実装）: 商人・装備・回復薬。効果・価格・枠を具体化し、残高不足、購入の二重処理、装備変更時の現在HPと最大HPを検証する。箱の中身は種類付きの配列にして拡張箇所を用意した。
