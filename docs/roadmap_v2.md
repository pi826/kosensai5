# 第2版の段階実装計画

作成日: 2026-10-16。各段階を遊べる状態で区切り、操作・構造・敵・成長・素材を順に検証する。

## 決まった方向

- 2026-10-25のユーザー決定: ワールドは壁を持つ塔と吊り橋で構成する。橋の高さ・本数・間隔はそろえず、両方向に渡れる。塔の外壁は橋の出入口以外をふさぎ、橋から谷底へは落ちない。中ボスは各地域で唯一最も高い塔の屋上に置く。

- 最終目標は、探索マップの3か所にいる中ボスをすべて倒すこと。最終区間のボス1体を倒す旧ルールから変更する。
- 第2段階での復帰は、同じマップを最初から。通常敵・中ボス・探索状況をすべて初期化する。戦闘込みの目標は1ラン5〜10分。
- マップは地形が一続きの単一ワールドとし、歩行・ジャンプで上下にも探索する。探索中にロード、部屋切り替え、移動キーでのワープを挟まない。3地域を背景で見分けられるようにし、探索済み地形のミニマップを用意する。
- 地形はグリッドに配置し、上下左右と斜めの8近傍からタイルを自動接続する。「8方向」は地形の接続を指す。
- 同色吸収・異色ダメージの基本は継続する。吸収は誘導弾ゲージをためる役割。
- **通貨は敵撃破で獲得する。装備購入などで強化し、独立した経験値レベルは作らない。** 吸収による通貨獲得は行わない。
- 2026-10-25のユーザー決定で、既存の通常敵3種類を残し、「弧を描くレーザー・地形破壊・地形設置・飛行」の4種類を追加する。通常敵は合計7種類とし、攻撃・移動・地形との関係で違いを作る。
- 鍵で錠付きの箱を開け、二段ジャンプを解放する。商人で回復アイテムや装備を買えるようにする。

## 1. 操作と基礎表示 — 実装・自動検証済み

- HP100の整数ゲージと現在値を表示。通常被弾12、誘導弾18を初期値とし、将来の回復や装備を扱える単位にする。
- 最高速度まで約6フレーム、停止約3フレームの地上操作。空中は強めに制動する。
- ジャンプを高くしつつ素早く着地する。短押しと長押し、0.1秒のコヨーテタイム、0.12秒の入力予約、小さな天井角の補正を実装する。
- ジャンプの伸び、着地のつぶれと土埃で動作を伝える。衝突形状は表示の伸縮で変えない。
- タイトルと一時停止からキー設定を開く。各操作2キー、変更の保存・再読込、重複の拒否、既定値への復帰、案内表示への反映を行う。
- 検証: HP・戦闘の回帰、実物理での操作補正、1,000シードの生成、3シードの走破、設定UIと保存。
- この段階では従来の横長マップとボス1体を使い、操作の変化を比較できるようにする。

## 2. 縦探索・3地域・3体撃破・ミニマップ — 実装・自動検証済み

- 横一列の区間から、上下に探索する単一マップへ作り直す。初期グリッドは32px。初期サイズは12,288×3,072px。
- Task 3では9本の塔を不均一な高さ・本数の吊り橋で結ぶ。塔の内部は96〜160px間隔の足場と固体の内壁で登り、屋上の昇降口から下りられるようにする。タイルの選択は8近傍で扱う。
- 3地域に1体ずつ中ボスを置き、識別番号で撃破状態を記録。3体すべての撃破をクリア条件とする。
- カメラは小さな動きを吸収しながら上下左右へ追従する。速い落下では下を先に映し、着地先とプレイヤーが画面内に残るようにする。
- ミニマップに現在位置・探索済みの地形・現在の視界・発見した中ボスを表示する。未探索の地形を最初からすべて明かさない。
- 素材ができるまでは地域ごとの仮背景色を使い、後で画像を差し替える。
- 検証: シード再現、塔・出入口・橋・屋上の往復、全中ボスへの実歩行での往復、地域境界での状態保持、落下中のカメラ、3体撃破の順序と重複、ミニマップの一致。
- 死亡時の完全リセットと5〜10分の目標を継続する。所要時間・難易度は人の実プレイで調整する。
- 第2段階の仕様と検証の詳細は `seamless_world.md`。部屋方式だった時点の記録は `phase2.md`。第3段階の追加分は `phase3_enemies.md` に記録する。

## 3. 通常敵4種類の追加と塔のワールド — Task 1・2・3実装済み

2026-10-25のユーザー決定で元の5種類案を変更した。

- 既存の turret（固定砲台）・walker（地上巡回）・shifter（色切替）は残す。
- Task 1実装済み: flyer（飛行）・laser（弧を描くレーザー）。
- Task 2実装済み: breaker（地形破壊）・builder（地形設置）。通常敵は7種類。床の表面64px・壊れるブロック・一時的な壁を実行時に変更する。開始と中ボスの塔・橋・外壁・内壁・屋上を保護し、通常ジャンプでの往復を維持する。
- Task 3: 塔・吊り橋・外壁の出入口・屋上の胸壁を追加。初期ジャンプでの往復と谷底への到達不可を、生成検証と実物理の試験で確認する。現在の結果は `seamless_world.md`。
- 元の案の「接近し、射撃時は距離を取る敵」「足場を跳び移る敵」は保留。walker・shifterの移動仕様の拡張も今回の変更には含めない。

- 同色吸収・異色ダメージは共通処理を使う。耐久力だけで役割を分けない。
- 地上敵の支持面、飛行敵の移動領域、壁や足場端での方向転換を生成データから決める。
- Task 1の検証: 1,000シードで両追加種を保証、飛行レーン、実弾による2発撃破、レーザーの予告・遮断・吸収・被弾・停止・消去、地域境界での状態保持。項目数と結果は `phase3_enemies.md`。
- Task 2の検証: 1,000シードの両追加種・ブロック配置・飛行敵の下の空間、実物理による穴・壁・砲弾、破壊後の往復、ミニマップ、境界保持と再挑戦。実行結果と爆発20回の処理時間は `phase3_enemies.md`。
- 異なる高さ・敵の組み合わせでの難易度と見やすさは、人の実プレイで確認する。

## 4. 鍵・箱・二段ジャンプ・商人・装備

- 初期能力で鍵と箱に到達できる順序を保証し、開封で二段ジャンプを解放する。
- まず二段ジャンプは上段の寄り道や近道の解放に使う。必須経路へ組み込む場合は、位置と所持能力を合わせて到達可能性を検証する。
- 通常敵と中ボスの撃破で通貨を得る。二重撃破通知から重複して通貨を得ないようにする。
- 商人から回復アイテムと装備を購入する。装備の効果・価格・装備枠は、この段階の開始時に具体化する。
- 検証: 鍵取得→消費→開封、解放状態、二段目の再使用防止、帰還可能性、残高不足、購入の二重処理、装備変更時の現在HPと最大HP。
- 通貨・装備・能力の死亡時の扱いは、復帰ルールと合わせて確認する。

## 5. 画像と音

- 地域3種類、プレイヤー、通常敵7種類、中ボス、鍵・箱・商人の画像を生成して組み込む。32pxグリッドと敵の輪郭が固まってから制作する。
- 8近傍の地形タイルを用意し、生成結果へ割り当てる。背景は弾の青・橙と見分けやすい彩度にする。
- ジャンプ、着地、射撃、吸収、色切替、被弾、開封、購入の効果音と、地域ごとの背景音を加える。音量調整を用意する。
- 検証: 色の識別、タイルの継ぎ目、画像と衝突形状の対応、音の重なり、操作と効果音のタイミング。
