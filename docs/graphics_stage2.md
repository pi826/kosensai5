## 原画と作成手順

組み込みimage_genで新しい原画を1枚生成。`assets/art/source/stage2.png` に保存し、
プロンプト全文は同じ場所の `stage2-prompt.txt`、生成記録はQAの `generation.json`。
外部素材やAPI/CLIの画像生成は使っていない。既存原画4枚も引き続き使用する。

`art_tools/build_art.py` が第1段階と `build_stage2.py` を順に実行してmanifestを作る。
通常敵の大部分は既存 `enemies.png`、ボス3種と灯籠・弾・氷片・火球・爆弾・矢印は新原画から切り出す。
胴・冠・左右の腕/砲・足・核を重ならない高解像度マスクへ分け、関節回りに回転・移動してから縮小する。
橙の胴体は青の同一部品のアクセントを変換し、冠と核は炎の形の別部品へ差し替える。
部品PNGは `source/parts/`、切出し座標・キーフレーム・速度はPythonに保存。
同じPillow 12.3.0 / numpy 2.3.5環境で決定的。別バージョンの減色結果までは保証しない。

全43シートは63色＋透明色以内、アルファ0/255、最近傍、ミップマップなし、可逆圧縮。
ボスにも色数の例外は設けていない。原画と部品は `source/.gdignore` でインポート対象外。
手順は [art_tools/README.md](../art_tools/README.md)、出典は [CREDITS](../assets/art/CREDITS.md)。

## 表示の決定

- laserは据置砲台、breakerは投擲腕、builderはブロックとクレーン、shifterは核を囲む機体、
  enhancerは浮く灯籠。idle 4 / move 8 / windup 3 / fire 3 / hurt 2 / death 6コマ。
  switchとwindup_switchも両色で用意する。enhancerの行動は増やさず、核の脈動のみ。
- guardianは双砲の二脚、finalは長い分節腕を持つ縦長の浮遊機、secretは6枚の装甲花弁を持つ環状機。
  見かけの高さは151 / 182 / 214px。判定は元の106×116 / 140×140 / 164×164。
  320×320セル、足元(160,275)。腕、砲、核、冠を別々に動かす。
  windup_special・fire_special・switchを持ち、deathは8コマ/8fpsのゲーム内1秒。
  当たり判定のある本体は直ちに削除し、衝突のない表示だけを兄弟ノードへ残す。
  スロー中は死亡時計も遅く進む。画面歪みは既存の実時間時計を維持する。
- 切替予告の最初から次の色の冠を表示し、核も続いて入れ替える。文字と警告弧を残す。
  ボスのHPは冠より上へ移す。HP数字、ロック、ゲージ、吸収弧、強化の輪と範囲を維持。
- 弾は自機の通常/誘導、敵の通常/誘導の4種×両色、各4コマ。
  自機は細いダート/白いミサイル、敵は幅のある破片/棘と小片の集まり。
  青は結晶、橙は火の舌を使い、進行方向へ回転。尾を保ち、暗い縁を付ける。
  サイズは表示のみで、衝突は従来の線分掃引を維持する。
- レーザーの予告と本体は両色の帯を曲線の各区間へ描き、ソース座標を時間でスクロールする。
  経路、クリッピング、発射時の色、接触判定は変更しない。
- 爆弾は脈動する機械と導火線。予告・飛行中とも画像を使い、元の爆発範囲表示を残す。
  設置壁は元と同じ中立の砂色。出現直後と消滅直前の各0.2秒でタイルを伸縮する。
  衝突の設置/削除時刻と点滅条件は変えない。ボス方向矢印は金属の金色の矢印。
- defeat / hit / absorb / switch / land / jump / bombにdashを加え、各6コマの氷片/火の粉へ置換。
  表示時間0.45秒と同時100個の上限を維持し、一つのburstは一回のシート描画。
  ダメージ、HP、チャージ、結晶の数字は文字のまま。

`-- --art-set=shapes` は従来の図形描画を選ぶ。画像の選択は物理、移動、乱数、HP、攻撃値、
同色吸収・異色ダメージ・発射後の色保持、地形生成、一続きの世界に関与しない。

## 第1段階の修正

1. cell_hashに右シフトXORと奇数乗算の混合を追加。足場の%3と石の%4に同じハッシュを使う。
   Pythonの見本とGDScriptの実ゲームの式を揃え、16×16セルを4セルずつ横・縦・斜めへずらして比較する。
2. 左右の明るい縦線を廃止。暗い不規則な石の縁と、上面につながる短い苔の垂れにした。
3. 斜め近傍が欠けた際に描いていたL字線を廃止。内角の外への突出を描かない。
4. 直上のマスクが露出上面である内部セルを少し明るくする。深い内部は元の暗さ。
5. インポート済み画像はResourceLoaderのスレッド読込、キャッシュなしはworkerでPNGバイトをデコード。
   描画時に同期読込せず、起動時に全43シートを先読みする。完了した仕事のみ回収し、1フレーム1.5msを予算にする。
   単一転送は分割できないため予算を超える可能性があり、操作単位・フレーム単位の最大時間を記録する。
   未読込中は図形を表示し、全先読み完了後は地形の再描画を要求する。
   欠損・破損IDだけ図形へ戻して警告を1回、他IDの成功を保持。headlessは先読み・デコード・GPU生成を行わない。

将来のexe書き出しでは、全リソースを含めるか、動的参照の全PNGをリソースとして選ぶ。
非リソースのmanifest用にexportの **`include_filter` に `assets/art/manifest.json`** を指定する。
export_presets.cfgは作っていない。インポートされたリソースを使う設計だが、exe書き出し自体は未検証。
