# 第2段階：縦探索・3地域・中ボス3体・ミニマップ

2026-10-16。全体の計画は `roadmap_v2.md`。第1段階の操作・色判定・整数HP・ダメージ表示を引き継いだ。

## 確定したルール

- 同じマップを最初から再挑戦する。死亡時には中ボスを含む全敵が復活し、探索・撃破状況・体力・ゲージ・スコア・経過時間を初期化する。
- 1ランの目標は、戦闘をしながら5〜10分。回避や熟練操作による短縮は認める。この所要時間は実測済みとはしない。
- 3地域の奥の中ボスを全員倒すとクリア。倒す順番は自由で、撃破後の帰還や別地域への移動も可能。通常敵の全滅は不要。

## マップと移動

- 開始部屋1室から、西・東・北へ3地域が分かれる。各地域は初期4室、計13室。枝の折り返しや上下の接続、足場、敵の種類・配置・色をシードで決める。
- 部屋は1280×736px、地形のグリッドは32px。足場の上面も32pxにそろえ、厚さ16pxの薄い足場は下から通過できる。
- カメラは部屋の中心で固定。通路に近づいて部屋移動キー（既定E）を押すと隣室へ切り替わる。移動は上下左右の相互接続で、帰路の通路も必ずある。
- 上の通路には、高低差128pxの足場3段で登る。初期ジャンプだけで移動できる。二段ジャンプや誘導弾は不要。
- 足場から落ちても連続した下の床に着地でき、落とし穴はない。入り口と進入位置の近くには敵を置かない。
- 部屋移動時は飛んでいる弾と表示エフェクトを消し、予約中のジャンプ・誘導弾入力を解除する。0.45秒の移動制限で連打による往復を防ぐ。
- 敵はプレイヤーのいる部屋だけで行動する。入室後1.1秒待ち、さらに攻撃の予告を出す。別室へ移って戻る間は、生きている敵のHP・ゲージ、撃破済みの状態を維持する。

## 地形・背景・地図

- 地形の上下左右と斜めの8近傍を調べ、仮タイルの外縁と内側の角を自動で描く。斜めだけが触れる場合は接続しない。
- 翠の水路・紫晶の回廊・灰燼の遺構を、暗い緑・紫・灰赤の背景と図形で分ける。生成画像と音は第5段階に残す。
- 右上のミニマップは訪問済みの部屋だけから表示範囲を計算する。未探索の部屋、未発見の中ボス、接続先の全配置は明かさない。
- 現在地は白枠、発見済み中ボスは菱形、撃破済みはチェックで表示する。HUDに探索数と3体の撃破数を併記する。
- 敵・中ボスのHPは整数だけを表示。ダメージ数値は実際に減ったHPを示し、吸収では出ない。
- 追加調整：通常敵のHPを8から2へ変更し、異色の通常弾2発で撃破できるようにした。通常弾は1ダメージ、同色吸収の規則は継続する。ボスHPは80。

## 生成の検証と復旧

生成データで、部屋の重複、上下左右の対応、逆向き通路、全室への到達と帰還、連続した安全床、ジャンプごとの足場到達、頭上の余白、進入位置の支持面、敵の埋まり・安全域、中ボス3体の固有IDを調べる。

通常生成に失敗した場合は最大12回まで再抽選し、最後に検証済みの固定枝構成を使う。フォールバックも同シードで再現する。到達性はグラフ検証だけでなく、実際のプレイヤー物理による走破でも確認する。
