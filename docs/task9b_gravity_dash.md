# Task 9B：重力反転と4方向の空中ダッシュ

2026-11-03。Godot 4.7.2 / GDScript。Task 9Aのボス部屋・行動、一続きの探索、同色吸収・異色ダメージ・発射後の弾色保持を維持。

Task 9Dでダッシュを画面基準の8方向（上下優先は廃止）とし、ダッシュ中の方向転換・開始時の画面振動・残像を加えた。上部の帯の色と射撃方向の表示は削除した。以下の4方向・上下優先の記述は当時の記録。現行は [Task 9D](task9d_dash_aim_dynamite.md)。

## 操作と仕様

| 既定キー | 操作 |
|---|---|
| A / ←、D / → | 左右移動、横ダッシュの方向 |
| Space | 通常ジャンプ、長押しで滑空（解禁後） |
| W / ↑ | 上ダッシュの方向 |
| S / ↓ | 下ダッシュの方向、通常重力で薄い足場を降りる |
| 方向＋Shift | 空中ダッシュ（解禁後）。方向なしは向いている方 |
| F | 自機だけ重力を上下反転。初期状態から使用可能、練習中は無効 |

他の既定キーは変更しない。全15操作を各2キーまで割り当てられる。ダッシュの操作名は「空中ダッシュ（方向と同時に押す）」、下は「下へ降りる／下へダッシュ」。新規2行を既存のスクロールへ追加し、長い操作名を折り返す。

保存はversion 4、読み込みは3と4に対応する。v3のjumpが旧既定[Space,W]の場合だけ[Space,None]へ移行する。保存済みの行は従来の検証規則で読み、保存に無い行には他の操作で使われていない既定キーを補う。両方空なら予備キー R、G、C、X、Z、V、B、T、Y、U、I、O、P、H、N の順で、補充済みの操作も含めて未使用かつ割り当て可能な最初のキーをslot 0に補う。予備も空きが無い場合だけ全体を既定値へ戻し、最後の重複検査も維持する。Fを他の操作で使うv3設定はその割り当てを保持し、gravity_flipには通常Rを補う（Rが使用中ならG以降）。カスタムjumpにWが残る場合はmove_upに↑だけを補い、↑も使用中なら同じ予備キー規則を使う。読み込みだけで保存ファイルを書き換えない。操作説明と能力解禁の説明は現在の割り当てを表示する。

### ダッシュ

二段ジャンプの定数・状態・分岐を削除。空中ジャンプの再押下で跳び直さない。通常のコヨーテ時間・着地前のジャンプ予約と短押しによる切り上げは維持する。

空中、能力あり、未使用、ダッシュ中でないときに発動。`v=下-上`、`h=sign(右-左)`とし、vが非ゼロなら上下、次に左右、入力なしならfacingを使う。上下優先、斜めには動かず、方向は反転中も画面基準。横入力で発動したときはfacingも更新する。

時間0.18秒、速さ960px/秒、60Hzでは11フレーム・176px。着地まで1回、地上では発動しない。ダッシュ中は方向×速度で上書きし、重力と滑空を止める。横は壁、縦は床または天井で終了する。終了時xは通常の横入力速度。yは横ダッシュと重力に逆らう縦ダッシュで0、重力と同じ方向の縦ダッシュでは`MAX_FALL_SPEED * gravity_sign`。画像のdash状態を維持し、図形の残線は進行方向の後ろへ描く。

### 重力反転

`gravity_sign`は通常1、反転−1。`up_direction=(0,-gravity_sign)`。接地でflip_readyを回復し、接地後に空中で1回まで反転できる。床はその時の重力に対して判断するので、反転時は天井の下面へ立つ。押下をpending_flipに保存し、物理フレーム間の短押しも受け付ける。

反転時はダッシュ、滑空、コヨーテ、ジャンプ予約、すり抜けを解除し、そのフレームを非接地として扱う。滑空は反転フレームには再開せず、ジャンプを保持していれば次フレームから新しい重力での落下時に再開できる。速度は保持し、鉛直処理は局所速度`velocity.y * gravity_sign`で計算する。ジャンプ、切り上げ、重力、落下上限、滑空、着地の強さは従来値。天井の角補正と演出位置も重力に合わせる。既存switch演出とair_jump音を使う。

薄い足場のmaskは通常重力で、すり抜け中でないときだけ有効。反転中は上下両方向に通過する。下キーによるすり抜けは通常重力のときだけ。厚い岩や設置壁との衝突は保持する。

反転時は画像・図形を上下反転し、当たり判定は変えない。射撃方向と銃身のyを反転するため、「上」撃ちは画面の下を向く。カメラの落下先読みも局所落下速度で判定し、反転時は画面の上を先読みする。gravity_signのないプレイヤーは通常重力として扱う。左上の目的・矢印の下（44,212）へ「重力反転中」を出す。下端の操作説明は3行に収める。

再挑戦・新しいラン・チュートリアルは新しい自機を作り、通常重力から始まる。チュートリアルは反転と能力を受け付けない。敵・弾・爆弾・ハート・収集物の物理は変更していない。

## 能力・宝箱・寄り道と計画

能力ビットはDASH=2、GLIDE=4。箱は開始区画の4方向ダッシュと、従来と同じ距離2〜4の抽選方法による滑空の2つ。距離2〜3の旧ダッシュ箱は無くした。解禁通知には現在設定の上下左右・ダッシュのキーを表示する。

開始区画の寄り道はDASH、他はDASHまたはDASH|GLIDE。DASHの前段は初期能力、両方の前段はDASH。前段では届かず、必要能力で届き、初期能力で帰還できる条件を維持する。上昇する辺の上限320pxも維持する。

`ABILITY_FLIGHT_SCHEDULES`の5予定を順番に複製して使用する。ダッシュ予定は横24フレーム、上22フレーム。計算順は実機の加速→重力→滑空→ダッシュ上書き→移動に合わせ、踏切の最初のフレームには地上加速を使う。キャッシュは`Vector3(from.x,from.y,profile.key)`、実測表はprofile.idで引く。

追加の保守的な経路選択として、上ダッシュの踏切を可能なら目標の左右192px側へ寄せ、上ダッシュ中に薄い足場と体の掃引矩形が重なる計画を除外する。Godotのone-way足場の衝突補正で約3pxの追加移動が発生する経路を到達保証に使わず、既存の最大移動量の閾値を維持するため。手動操作で上ダッシュが薄い足場を通過する挙動は保持する。

生成の到達保証は通常重力のジャンプ・ダッシュ・滑空だけを使う。重力反転で能力なしに寄り道の棚へ届く場合があることは仕様として許容する。

### 実物理の測定値

平地・静止から右へ入力、60Hz。上昇量と距離はpx、フレームは着地まで。滑空なしは通常ジャンプの頂点に達する23フレーム目以降にjumpを離す。数値は実際のCharacterBody2Dと入力で測定し、以下をtuning.gdへ記録した。

|---|---:|---:|---:|---:|
| dash_side | 2 | 173.0190 | 394.5601 | 54 |
| dash_up | 2 | 349.0190 | 271.8931 | 64 |
| glide | 4 | 173.0190 | 575.8934 | 110 |
| dash_side_glide | 6 | 173.0190 | 757.2260 | 122 |
| dash_up_glide | 6 | 349.0190 | 1045.2251 | 209 |

通常ジャンプは173.0190px・213.2265px・42フレーム。上ダッシュは通常より176px高い。実物理と表は高さ・距離0.2px以内、フレーム一致。解析側の弧とも0.2px以内で照合する（Godotの接触余白による高さ差約0.075pxを含む）。
