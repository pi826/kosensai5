## 店と装備

買う画面の領域は1014×352px。左に236×170pxの回復薬・鍵を上下に置き、右に248×352pxの装備1枚と247×170pxの装備4枚を2列で置く。間隔は12px。装備3品の店では376×352pxの大カードと378×170pxの小カード2枚、装備4品では248/247×352pxの大カード2枚と247×170pxの小カード2枚に組み替え、余分な空列を残さない。最大7品が収まり、スクロールは使わない。ピンクの瓶・金の鍵・青の銃・緑の盾・紫の菱形を描画し、同じ色の帯で種類を示す。カードに名前・効果・価格・購入可／不足／所持／上限／売り切れを表示し、買えない品物は暗くする。

装備画面は幅330pxの3列（間隔12px）。各列の上は330×120pxの現在の装備、下は330×50px（間隔6px）の他の所持品と「外す」。空き枠で全3候補を持つ場合も352px以内。未所持なら「まだ持っていません」。候補の効果はマウスを重ねた際の説明、現在の効果は大カードに表示する。

矢印でカードと上のボタンを2次元に移動し、Enter・Spaceで決定。Tabは買う／装備切替、マウスも使用可能。Esc・現在の調べるキー・一時停止キーで閉じる。任意設定で調べるをEnter等にした場合は閉じる操作を優先する。キー押下から解放まで1回、UIと購入処理の両方の実時間0.2秒制限は維持した。一時停止からは装備のみ。

プレイ中の現在装備は右上の地図の下、x=902〜1256、y=236/262/288の3行。空き枠に付けられる所持品があれば黄色で「防具 なし ← 厚い外殻を付けられます」等を表示し、y=318に「Esc → 装備 で付け替え」（現在の設定キーへ追従）、一時停止の「装備」に●。付けると消える。チュートリアルでは出さない。開始時の案内と通知の幅も調整し、装備表示と重ならないようにした。

## 大きな地図

新操作 `world_map`（地図、M）をキー設定へ追加。version 3を維持し、以前の設定に行がなければMを補完する。既存キーとの重複拒否と読込時の全既定値への復旧は従来の処理を使う。

Mで開き、M・Esc・現在の一時停止キーで閉じてプレイへ戻る。ワールドのサブツリーとゲーム内時刻を止め、開くたびに自分を中心・既定倍率にする。矢印／WASDとドラッグで移動、ホイール・+/-（テンキー含む）で拡大縮小、Spaceで自分へ戻る。ホイールはカーソルの指す位置を固定して倍率を変える。画面下に操作、上に図形による凡例。チュートリアルでは無効。一時停止への地図ボタン追加は任意のため行わない。

探索セルは128px。整数の安定セル座標（区画座標と区画内セルに一意に分解可能）で輪郭の矩形を保持し、隣接矩形を横・縦に結合する。新規観測時と地形revision変更後の再観測時、および区画解放前に更新する。区画別の探索セル索引は既存のものを利用する。矩形はセル内の位置なので原点移動による書き換えを要しない。遠方も区画座標の差を取ってから描画座標へ変換する。再挑戦で全記録・画像・描画キャッシュを消す。

開くときに大量のセルを再描画しないよう、観測時に区画別128×96pxのRGBA画像（地形32pxにつき1画素）を更新する。地形の輪郭と地域色を描き、薄い足場は最低1画素に丸める。大きな地図では範囲内の区画画像を各1回描画し、変更した区画だけテクスチャを更新する。画像は未探索部分を透明にし、探索済みの岩と空間だけを記録する。輪郭の矩形記録は画像と別に保持する。右上の地図は従来の描画を共通関数へ移しただけで、範囲・印・実地形からの描画を維持する。

ボスの種別・撃破チェック・商人の家・金の鍵／箱・紫の能力箱は小さい地図の処理を共用する。自分は白点と輪・十字、区画境界は薄い線。探索した全区画へ移動して見られる。地図の外は描かず、境界線が凡例や操作説明へはみ出さない。

## 負荷と制限

300区画を全探索した場合（230400セル）を合成し、最低倍率で300枚の区画画像を表示する。RGBA画像だけで14745600bytes（約14.1MiB）、GPUテクスチャも同程度。探索辞書・矩形・エンジン内部領域は別。通常描画（NVIDIA GeForce RTX 3060）のCPU描画命令発行は初回7.566ms、更新時平均13.172ms／最大15.11ms。フレームの経過時間は平均15.318ms／最大17.198ms。headlessでは初回1.266ms、更新時平均0.658ms／最大0.859ms。画像と合成記録の準備時間は描画計時に含めない。記録量を増やしても開く際に全セルを走査せず、表示区画だけを描く。CPU描画命令の発行時間と通常描画フレームの経過時間を区別し、GPU単独の処理時間とは扱わない。

仕様からの機能上の逸脱はない。地形の32px単位の簡略化は大きな地図だけで使う。見た目の好み、初見の人による文章の理解度・手動での操作感、長時間の実プレイ、exe書出しは未確認。画像の目視と自動入力はこれらの代わりにはしない。
