# Task 9E（2026-11-05）

Godot 4.7.2 / GDScript。一続きの探索、同色攻撃の吸収、異色攻撃のダメージ、発射後の弾色保持を維持する。

## ダイナマイトの入手・上限・導火線ゲージ

- 入手条件: 自機の攻撃で通常敵を3体倒すごとに1個。数えるのは読み込み済み・生成済みの通常敵で、倒した時点の撃破記録が自機の攻撃によるものだけ。`dynamite_kill_progress` は区画や chamber_id をまたいで数える。
- 数えない撃破: チュートリアル中の撃破、自機が無効または死亡中の撃破、ボス、召喚された敵、`defeated_enemies` に記録済みの敵を `_restore` で戻して倒し直した場合、自機の攻撃でない撃破。`kills` と同じく、撃破処理が実際に通った通常敵だけを対象にする。
- 3体目の処理: 進捗を0に戻し、所持数が上限未満なら1個増やして `ダイナマイト入手 n/20`、上限なら `ダイナマイトは満杯です` を通知する。どちらも既存の `charge` 音を出す。上限でも進捗は0に戻る。
- 上限: `DYNAMITE_CAPACITY` を20に変更。`DYNAMITE_GROUP_MIN` は削除し、`DYNAMITE_KILLS_PER_STICK` を3として追加した。
- 状態: 所持数と撃破進捗は区画の再読込をまたいで保たれる。自機の死亡、再挑戦、新しい run では両方0に戻る。区画ごとの `dynamite_claimed` と `claim_dynamite_room`、`sector_stream.gd` の `room_cleared` は削除した。
- HUD: チュートリアル以外で、満杯でなければ `ダイナマイト n/20  あとk体`、満杯なら `ダイナマイト n/20  満杯` を表示する。ラベルは従来の位置 (524, 80)・幅250px のままで、最長の `ダイナマイト 19/20  あと3体` が収まること、右隣の収集表示 (x=840) と重ならないことを検査した。`art_skin.gd` の HUD 画像は y=25 の誘導弾と x=844 以降の収集物で、ダイナマイト表示とは重ならない。
- 導火線ゲージ: 爆発前だけ、棒の中心 (0, 0) に半径22pxのリングを描く。下地は黒の半透明・幅5px。残り時間の弧は真上（-PI/2）から時計回りに `TAU * remaining`、幅3pxで描き、残りが0なら描かない。色は `Color("f5bd68")` から `Color("ff5a4a")` へ残り時間に応じて補間する。
- `dynamite.gd` の `fuse_remaining()` は `1.0 - elapsed / DYNAMITE_FUSE` を0〜1に制限して返し、`_draw()` と検査で使う。物理・爆発・掘る範囲・ダメージは変更していない。

| 定数 | 値 | 意味 |
|---|---:|---|
| DYNAMITE_CAPACITY | 20 | 所持上限 |
| DYNAMITE_KILLS_PER_STICK | 3 | 1個入手するのに必要な通常敵の撃破数 |
| DYNAMITE_GAUGE_RADIUS | 22.0px | 導火線リングの半径 |
| DYNAMITE_GAUGE_WIDTH | 3.0px | 残り時間の弧の幅 |

## 中ボス以上の弾幕

Task 9E-2（2026-11-05）。ボスの通常射撃から1発だけの斉射をなくし、扇を撃つ攻撃は1回目と0.25秒後の2回目に分けた。2回目はその時点の自機方向へ向け直し、1回目の扇の間へ `BOSS_FAN_ANGLE / 2` だけ回転させた逆色の扇を撃つ。発数は1回目と同じで、誘導弾は付けない。2回目も `boss_shot` を鳴らす。

| 役割×pattern | 1回目の斉射 | 2回目の斉射 |
|---|---|---|
| guardian 0 | 5発（ボスの色） | なし |
| guardian 1 | 5発（ボスの色） | 5発（逆色） |
| final 0 | 5発（ボスの色） | 5発（逆色） |
| final 1 | 5発（ボスの色、`sin(move_clock)` ずらし）＋誘導弾1発 | 5発（逆色） |
| secret 0 | 7発（ボスの色）＋誘導弾1発 | 7発（逆色） |
| secret 1 | 7発（ボスの色、`sin(move_clock)` ずらし）＋誘導弾1発 | 7発（逆色） |

- 1回目と2回目の扇は共通の `_fire_fan(direction, count, color, offset)` で撃つ。角度は `(i - (count - 1) / 2.0) * BOSS_FAN_ANGLE + offset`。
- 2回目は `second_volley` action で `BOSS_SECOND_VOLLEY_DELAY` 待つ。移動は警告中と同じく続ける。`cancel_attack()`、画面外、撃破で idle に戻れば2回目は撃たない。
- 2回目がある攻撃では1回目に `shot_clock` を設定せず、2回目の完了時に `_base_shot_interval()` を設定する。guardian pattern 0 は1回目の完了時に設定する。
- ラスボス（`boss_role == "final"`）だけ、`hp < max_hp * FINAL_BOSS_RAGE_RATIO` で常時回転弾を出す。ちょうど半分は含まない。guardian と secret は対象外。
- 常時回転弾は画面内かつ起床待ち終了後、`spinning` 以外の action で毎フレーム更新する。4本を0.24秒ごとに撃ち、腕の色は偶数がボスの色、奇数が逆色。発射位置は `position + muzzle_offset(direction)`、音量は `-10.0`。
- 体力が半分を切った最初の対象フレームで `switch` effect を1回出す。すでに `spinning` 中なら、その旋回が終わるまで発射を抑える。旋回終了後は再開する。
- 常時回転中は `_begin_signature()` が `spinner` を選ばず `false` を返す。`signature_index` は進むため、次の攻撃選択で `summoner` へ進む。体力が半分以上なら spinner は従来どおり。

| 定数 | 値 | 意味 |
|---|---:|---|
| BOSS_SECOND_VOLLEY_DELAY | 0.25秒 | 1回目から2回目までの待ち |
| FINAL_BOSS_RAGE_RATIO | 0.5 | 常時回転弾を始める体力比（この値未満） |
| FINAL_BOSS_RAGE_SPIN_INTERVAL | 0.24秒 | 常時回転弾の斉射間隔 |
| FINAL_BOSS_RAGE_SPIN_ARMS | 4 | 1回の常時回転弾の発数 |
| FINAL_BOSS_RAGE_SPIN_SPEED | 1.7rad/秒 | 常時回転弾の回転速度 |
