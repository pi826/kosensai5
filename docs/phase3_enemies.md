# 第3段階の敵

2026-10-25。Task 1で飛行敵・弧を描くレーザー敵を追加した。
Task 2で breaker / builder と変化する地形を追加し、通常敵は turret / walker / shifter / flyer / laser / breaker / builder の7種類になった。
既存3種類は維持し、walkerのみ壁・削れた床の段差で反転するよう変更した。

## 共通規則と構造

- HP2、異色の通常弾2発で撃破、100点。同色攻撃は吸収してゲージ+1。満タン時は共通の予告付き誘導弾を使う。
- 画面外では攻撃せず、退出で予告を解除する。再進入では1.1秒の起床待ちを取り直す。各敵は同時に複数の予告を進めない。
- 一続きの探索マップを維持する。地域境界では位置・HP・ゲージ・弾・レーザーを保持し、開始と再挑戦だけワールドを生成する。
- 一時停止・キー設定中はワールドの処理を止める。接触・落下ダメージは追加していない。
- `enemy.gd` の種類別移動・攻撃選択を分け、色判定・ゲージ・起床待ち・予告・誘導弾は共通処理を使う。

## Task 1: flyer

- 重力を受けず、床上面から176px上を中心に左右往復・上下揺れを行う。画面外では移動と揺れを止める。
- 幅384pxの床区間の左右48pxを除いた範囲を、中心の往復範囲とする。体の大きさ・揺れ・8pxの余裕を含む矩形が地形と交差する区間には置かない。
- 高いジャンプの頂点付近から撃つ水平弾で狙える。立位・短いジャンプの水平弾は届かない。攻撃は既存の通常弾と同じ予告・間隔。
- 翼と浮遊を示す輪郭で識別する。色・A/B・残HP・ゲージの規則は共通。

## Task 1: laser

- 地上固定。起床後に2.6秒待ち、0.6秒予告して0.3秒照射する。照射を終えてから次の間隔を数える。
- 予告開始時の発射口・プレイヤー中心・敵の色を固定する。制御点は弦の中点から上向きの垂線方向へ `clamp(弦長×0.35, 96, 320)` pxずらす。ほぼ垂直の弦は向いている側へ膨らませる。
- 2次ベジェ曲線を32線分に分ける。予告開始時と照射開始時に物理レイヤー1だけを調べ、最初の地形接触またはワールド外への出口で打ち切る。予告は点滅する細い破線、照射は太いビーム。
- 毎物理フレームで線分とプレイヤー矩形の距離を判定する。半径6px以内の最初の接触だけ `receive_hit(色, 14)` を呼ぶ。同色はゲージ+1・HP不変、異色は14ダメージ。無敵で防御された接触も消費し、後で再判定しない。
- 敵や弾には作用しない。`laser_beam.gd` を `projectiles` の子に置く。発射元の撃破・画面外への退出で消し、再挑戦でも消す。
- レンズと台座で識別する。予告・照射中は次の攻撃予告を始めない。

## 配置と再現性

- `NORMAL_KINDS` に候補をまとめ、飛行可能な枠だけflyerを候補に含める。flyerまたはlaserが不足したら、生成専用RNGで条件を満たす枠を選び直して置き換える。
- spawnの `floor_index` と `patrol` から飛行レーンを特定する。床との高度関係、区間内の往復、地形との非交差、開始地点の安全範囲を検証する。飛行敵には地上支持を要求しない。
- `signature` は種類・色・位置・往復範囲・床区間を含む。同じシードと設定では地形・配置が一致する。種類追加に伴う乱数の使い方の変更により、旧版と同じシードでも敵配置は変わる。

## Task 2: breaker / builder

- breakerは地上固定。起床後3.2秒間隔で0.6秒予告し、予告開始時のプレイヤーの足元と色を固定する。砲弾は重力900px/s²、飛行時間1秒から求めた初速で放物線を描く。予告中・飛行中は着弾印を表示する。
- 砲弾は地形・ブロック・プレイヤーへの最初の接触で爆発する。半径44px、異色16ダメージ、同色ゲージ+1。プレイヤー矩形と円の距離を使い、直撃を含め爆発1回につき1回だけ判定する。敵には作用しない。
- 飛行開始後の砲弾は発射元の撃破・画面外への退出でも残る。予告段階での退出・撃破では着弾印を消す。ワールド外へ出た砲弾は消去する。
- builderは地上固定。優先順位は満タンの誘導弾、壁設置、通常射撃。4.5秒ごとに設置可能な列を探し、0.6秒予告する。設置間隔は通常射撃の予告中も進む。
- 列はプレイヤー方向へ3〜6マス先、両者の間で、プレイヤー矩形から48px以上離す。同じ床高±64pxの最初の固体上面に接地し、高さ96px、障害物があれば64pxに縮める。薄い足場と一時壁は支持に使わない。
- プレイヤー矩形＋8px、全敵、地形、ブロック、他の壁と重なる候補、保護範囲内の候補を除外する。予告終了時にも距離・支持・重なり・所有数を確認する。有効な壁は所有者ごとに2枚まで。
- 壁の耐久は3、寿命8秒、残り1.5秒で点滅する。通常弾3発・誘導弾1発または爆発で壊せる。所有者を倒しても壁は消えない。爆発では範囲内に中心がある壁セルだけを除去する。

## 地形の分類と更新

| 分類 | 破壊条件 |
|---|---|
| 外壁・薄い足場・深い床 | 壊れない |
| 床の表面2マス（64px） | 爆発円の中に中心があるセルだけを除去。弾では壊れない |
| 生成時の壊れるブロック | 32pxグリッド、幅・高さ32〜64px、耐久3。プレイヤー弾のダメージ分だけ耐久を減らす。爆発円内に中心があれば全体を除去 |
| 設置壁 | 幅32px、高さ64〜96px、耐久3。プレイヤー弾、セル単位の爆発、時間切れで除去 |

表面の保護範囲は中央登攀路の下 `|x−6144|≤448`、地上中ボス `x=768,11520` の各±384px、外壁の内面から64px以内。ブロック・壁も保護範囲には置かない。
床区間の最大段差64px＋表面64px＝128pxは `T.MAX_STEP_HEIGHT`（約168.4px）以下。登攀路の1段目の下は削らない。壁も支持面の差64px＋高さ96px＝160px以下で、通常ジャンプで越せる。

`world_terrain.gd` が破壊セル、ブロックと耐久、壁のセル・所有者・残り時間・耐久を保持する。`stage.solids` と `stage.breakables` は変更しない。公開操作は `explode`、`damage_at`、`find_wall_plan` / `place_wall`、`is_cell_solid`。
壊れない部分の衝突は大きな矩形、表面・ブロック・壁は各行の連続セルを矩形にまとめる。変わった行だけ再構築し、変更セルと8近傍の接続情報、該当する512px描画単位だけを更新する。ミニマップは実行時地形の版とインスタンスIDでキャッシュを更新し、壁は表示しない。

物理レイヤーは次のとおり。`project.godot` にも名前を設定した。

| レイヤー | ビット | 用途 |
|---|---:|---|
| 1 | 1 | 地形・表面・ブロック |
| 2 | 2 | プレイヤー本体 |
| 3 | 4 | 敵本体 |
| 4 | 8 | 設置壁 |

本体のmaskは1＋8。プレイヤー弾は1＋4＋8、敵弾と砲弾は1＋2、レーザーは1を調べる。ブロックは敵弾・レーザーを遮り、設置壁はそれらと砲弾を通す。ブロックと壁への弾ダメージはプレイヤー弾だけが与える。

## Task 2の配置・継続状態

- 各シードでflyer / laser / breaker / builderを保証する。不足時は生成専用RNGで既存の枠を置き換える。壊れるブロックは8個を目標に置き、4個以上を検証する。
- ブロックは床に接地し、床区間の端から32px以上離す。開始地点の安全範囲、保護範囲、地形、敵の体と往復範囲、飛行レーン、経路通過点のプレイヤー矩形＋左右16pxと重ならない。配置と保護範囲をsignatureに含める。
- flyerの高度・速度・揺れは維持する。飛行レーンの下端と真下の薄い足場上面にプレイヤー身長＋8pxの空間がない区間には配置せず、validateでも拒否する。
- 地域境界で壊れた地形・壁と寿命・飛行中の砲弾を保持する。再挑戦では生成直後の床・ブロックと耐久を復元し、壁・砲弾を消す。一時停止・キー設定中はすべて止まる。
- Task 2の調整値はすべて `tuning.gd` の `SURFACE_*`、`TERRAIN_HP`、`BREAKABLE_*`、`BOMB_*`、`BUILD_*`、`WALL_*`、`PROTECTED_*` に置いた。
