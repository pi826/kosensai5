# 初版の実装仕様

これは2026-10-15の旧版の記録です。現在の第1段階の変更は `phase1.md`、今後の予定は `roadmap_v2.md` を参照してください。

## 戦闘

- 攻撃側の所属と弾色を別々に保持する。プレイヤーの弾は敵だけ、敵の弾はプレイヤーだけに当たり、どちらも地形に遮られる。
- 命中時に弾色と受け手の現在色を比較する。同色なら弾を消してゲージを1増やし、異色ならダメージを与える。通常弾と誘導弾で吸収規則を変えない。
- プレイヤーは被弾後1秒間、追加ダメージを受けない。この間も同色の弾は吸収できる。敵に無敵時間はない。
- 色切り替えは入力イベントで即時実行する。ジャンプと強攻撃の入力は次の物理更新まで保持し、短い入力を取りこぼさない。
- 通常敵は体力8、通常射撃は1ダメージ・毎秒4発。最初から最後の命中まで1.75秒、継続火力換算で2秒。
- 強攻撃は1ゲージにつき誘導弾1発で、上限8。プレイヤーは好きなタイミングで全消費し、敵は満タンで0.8秒予告して全消費する。プレイヤーの誘導弾は4ダメージ、敵の誘導弾は1ダメージ。
- 誘導弾の初期対象は画面内の生存中の相手。異色がいればその集合に均等に振り分け、いなければ同色も対象にする。対象消失時は異色優先・近い順で再選択する。対象の色変更だけでは再選択しない。
- 対象がいない誘導弾は前方へ直進し、その後に対象が見つかれば追尾する。弾の寿命は5秒で、発射後に色は変化しない。
- 敵への故意の同色射撃と、そこからの強攻撃の吸収を戦術として認める。吸収はスコアを生まない。

## 敵とボス

- 固定砲台、床の上を往復する射撃敵、色を切り替える射撃敵の3種類。各敵の弾色は自身の発射時の色。
- 画面外では攻撃しない。画面に入ってから1.1秒待ち、通常射撃の0.45秒予告を経て撃つ。
- 通常射撃、色切り替え、強攻撃の予告を同時に進めず、予告色と発射色が食い違うことを防ぐ。画面外へ出た場合は予告を解除し、再進入後に待ち時間を取り直す。
- 色変更は行動タイマーで決まり、プレイヤーの発射には反応しない。0.8秒の変更予告中は旧色の衝突判定。
- ボスは体力80。狙った方向への単発と5方向の扇状射撃を、色変更ごとに交互に使う。吸収による誘導弾も共通規則で使用する。

## 地形と生成

- 14区間、各1,280px。安全な開始区間、12戦闘区間、固定形状のボス区間で構成する。
- 戦闘区間は平地、低い段、台地、階段、上の足場、複数の上の足場の6種類から選ぶ。各区間の下には連続した安全床があり、敵撃破による通行制限は設けない。
- 薄い上段の足場は下からジャンプで通過でき、上からは着地できる。台地や階段は通常の立体地形として扱う。
- 入り口・出口の床高さをそろえ、境界の両側192pxを空ける。敵の配置は各足場の支持範囲と体幅を考慮する。
- 床の連続性、接続、地形の範囲、上面を通る経路の段差と踏み切り・着地幅、敵の支持と埋まり、最後のボス1体を検証する。
- 上面経路はジャンプの放物運動とプレイヤー幅を使って検証する。選んだ部品は上面経路の上に天井がない構造で、最大段差は84px。初期ジャンプの理論高さ108.9pxから12pxの余裕を取る。
- 最大12回の生成検証に失敗したら、安全床だけの構成を使う。シードと設定が同じなら再試行も含めて同じ結果になる。
- 乱数は生成専用のRandomNumberGeneratorを使う。再挑戦時に乱数依存の行動初期値を追加せず、敵の往復方向も再現する。

## ランの状態

- タイトル、プレイ、一時停止、失敗、クリアを持つ。メニュー表示中は地形・敵・弾・プレイヤー・演出の更新を止め、UIだけを操作できる。
- 再挑戦は同じシードから作り直す。体力5、ゲージ0、スコア0、経過時間0から開始し、敵も全復活する。
- 撃破スコアは通常敵100点、ボス1,000点。全撃破は4,400点。ボス撃破とプレイヤー死亡が同時なら失敗を優先する。
- 初版は図形表示とキーボード操作。音、回復、恒久成長、装備、セーブ、ゲームパッド、単独exe配布は含めない。
