# Task 7D：縦穴の横道と緩い段差通路

## 実装

- `VERTICAL_RUN_MAX=1024px`。全shaftと縦に続くゲート入口を柱にまとめ、高さ128px以上・柱の外へ256px以上続く床付き横道で区切る。短い通路から空洞へ続く横道も合成して測る。床の突起や削った床も実体から調べる。広い入口だけでは区切らず、その先に別の接続が必要。
- 上下の境界から最初の横道までは各区画512px以下。上下入口を横832pxに広げ、続く縦の接続をゲート柱から256px離して横道を確保する。上側入口は高さ384px。近接した左右入口と併合した後の床に合わせてゲート縦穴を作る。
- 直線shaftは704px以下を優先し、それを超える候補はelbowを先に試す。必要な場合だけ最大1,024pxの直線候補を重み8倍で木に使い、追加辺には使わない。これとは独立に、完成した全柱の実際の縦区間を検査する。上限の1,536pxへの緩和はしていない。
- 境界近くの入口が、下側の半上限より32pxだけ上に開く場合、共有境界の先に32pxの段差を置く。32/64pxの床下の隙間は岩で埋め、近すぎる下段の足場は横へずらす。共有境界の開口・最初の128px・足場の位相は維持する。
- elbowが上側入口の床を掘り下げた場合は、実際の床までゲートの足場を延長する（`_repair_gate_aprons`）。厚い岩がない範囲だけに既存の `_shaft` で足場と96pxの保護範囲を作り直す。足場間隔96〜160px・境界側の位相は維持する。`_trim_gate_steps` は対象の岩が見つからなければ変更を飛ばす。
- 斜めの足場列の生成・専用定数9個・配置・補助足場・空間予約・専用検証を削除。7Cの `_diagonal`（20〜50度・段64px以下）は変更していない。
- 緩い段差通路は段32px以下、踏み面64px以上、全体の傾き1/2以下（26.565度以下）、天井160〜256px、長さ2,048px以下。elbowの横部分にも最大192pxの緩い段差を付け、長い平坦部を減らす。折り返しは採用せず、横距離の足りない候補／空洞配置を選び直す。
- 通常空洞の追加候補は左右19：上下1、高低差の倍率0.25〜0.6。上側入口を基準にする候補では横の間隔384〜896pxを取り、区画の内側へ下る。空洞寸法・特殊空洞・空洞間の岩64pxは維持する。新しい緩い段床は接続先以外の空洞と他の接続から岩64pxを残す。
- フォールバックは両端の足場列を維持し、上端320px／下端2,944pxに他の場所へ続く横道を追加した。上段の通常空洞の高さは480pxとし、上の横道との岩64pxを確保する。
- 骨組みの段階で、内装では修復できない通路床の不成立と縦区間の違反を棄却する。最終validateの通路検査は同じ共用関数を使う。形状・保護範囲・岩の間隔・実地形の検査を追加し、通常／最大掘削後の全支持面の強連結、全ゲート、敵・ブロック・収集物・能力の寄り道の検証は維持する。

`source-before/` は編集前に保存した本体。測定用の `shaft_test.gd`／`vertical_runs.gd`／`diagonal_metrics.gd` と撮影用の `visual_check.gd` を同じ最終版で双方に置き、独立した変更前プロジェクトと本体で直列実行する。1,000区画はシード0〜199 × `(0,0),(1,0),(-1,1),(0,-1),(2,2)`。上下境目は各シードの `(0,-1)→(0,0)` と `(1,0)→(1,1)`、共有ゲート597本。追加の `(1,1)` は比較の生成時間に含めない。
