# Task 9C：ダイナマイトと深い岩の破壊

2026-11-03。Godot 4.7.2 / GDScript。Task 9Aのボスアリーナと攻撃、9Bの重力反転・4方向ダッシュ、一続きの探索を維持する。

## 入手・操作・被弾

- 同じ区画・chamber_idに通常敵が2体以上いる部屋が対象。強化の灯を含み、ボス・召喚敵を除く。通常弾・誘導弾・ダイナマイトで最後の1体を倒すと1個入手する。周回の追加配置データや未配置の敵が残る間は判定しない。
- 最大3個。同じ部屋は1回の挑戦で1回だけ。満杯でも入手済みとし、入手・満杯の通知と既存のcharge音を出す。区画解放・再読込・原点移動でストックと取得済み記録を保ち、死亡・再挑戦・新しいrunで初期化する。練習中は入手しない。
- 既定G、設定画面と操作説明から変更可能。全16操作、保存version 4を維持する。v3/v4読込時は保存済みの有効な割り当てを保持し、不足したdynamite行に未使用の既定値または予備キーを補う。Gを別操作に使った旧設定の保持を検査した。
- ストックがあり、自機が生存し、練習中でない場合に1個消費して自機位置から投げる。画面基準で向いている横方向と上向きの初速を与え、以後は常に画面下へ落ちる。自機の重力反転は影響しない。
- 横の衝突では横速度を止めて落下し、床・薄い足場に乗ると停止する。下の支持が壊れれば再落下する。導火線の火花と半径の予告円を表示し、投げて1.6秒後に爆発する。読み込み範囲の外へ出る場合は爆発せず消える。
- 爆発は色なし。体の矩形が半径に触れる自機・通常敵・召喚敵・ボスへ専用のreceive_neutral_hit経路でダメージを与える。自機の無敵時間・装備の軽減など既存の被弾処理に従い、敵撃破は自機の攻撃として既存報酬へ渡す。同色吸収・異色ダメージ・発射済みの弾色保持の分岐は維持する。商人・ハート・収集物は対象にしない。
- 爆発音はbomb_explode、描画は既存bomb演出を半径に合わせて使用する。HUDは誘導弾の近くに「ダイナマイト n/3」を表示する。

## 地形破壊の方式

セル中心が円内にある岩を、表層・深い岩・protected_rectsの区別なく消す。壊れるブロックはplayer_attack=trueで壊し、既存の回復規則を使う。設置壁は円内のセルを消す。厚さ16pxの薄い足場は壊さない。敵の爆弾が呼ぶexplodeは既存の表層・ブロック・壁だけの処理を維持する。

半径を含む格子の小さな正方形と交わる静的コリジョン矩形だけを外し、その正方形の外の岩を最大4矩形に分割する。正方形の中の生き残った岩は行のコリジョンへ移す。occupied・tile_masksと隣接セルの縁、行の衝突、描画チャンク、support_revisionを更新する。元の岩矩形の全セルを走査せず、区画全体の衝突や描画を作り直さない。処理量は局所セル・交差する矩形・行の状態に依存し、元の矩形の面積には比例しない。

読み込み済みの2区画をまたぐ爆発にも同じ処理を使う。未読込・解放処理中の区画には触れない。_cell_sectorの寸法はT.SECTOR_SIZE / TILE_SIZEから求め、負のセル座標も床関数で区画へ変換する。

## 保存・再読込・原点移動・外周

snapshotのdynamiteには、消した岩セルのholesと、静的矩形を行へ移した範囲のcutsを保存する。どちらも区画内の整数座標。SectorStream.statesに保持し、再読込では元の地形を組み立てた直後にcutsの衝突分割とholesの削除を適用する。既存の表層破壊・ブロック耐久の記録も維持する。生成データとsignatureの生成処理は変更していない。

原点移動では安定した整数セルキーと保存記録を保持し、既存の衝突ノードと投擲物の位置を移す。ゲーム本体のmaybe_shift_originを物理優先度の早いコールバックから呼び、既存の穴・周囲の岩・移動後の再爆発・飛行中の位置と速度と導火線・次フレームの軌道を検査した。

本編は上下左右に区画を生成する方式で、壊してはいけない人工的な世界外周はない。読込範囲の端は世界の外周ではなく、読込済みの側だけを破壊する。到達性・詰み防止の生成検査は依頼に従い追加していない。

保存は挑戦中のメモリ内の記録。アプリ終了後に挑戦を再開するディスク保存機能は追加していない。

## ミニマップ・全体地図

refresh_dynamite_mapは消したセルから探索済みの128px地図セルを選び、現在のoccupiedから地形断片と区画画像を記録し直す。区画画像のrevisionを増やし、ミニマップ・全体地図の各テクスチャキャッシュが次の描画で更新する。全体地図を開いた際にも最新画像を使う。未探索セルは新たに明かさない。

dynamite_testで爆発前後の画像画素が岩色から変化すること、周辺の残った岩の画素が同じこと、両地図の描画が新revisionの画像をキャッシュすること、未探索の破壊セルが透明のままであることを確認した。表示の元データと描画時のキャッシュ更新までをheadlessで検査し、人の目による見え方は未確認。
