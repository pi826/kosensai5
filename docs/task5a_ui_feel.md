# Task 5A：日本語表示・地図・ジャンプ・HP表示・接触ダメージ

2026-10-25。5Aのみを実装した。5B〜5Eの無限マップ・回復アイテム・報酬・復活・追加ボス・チュートリアルは未実装。

## 実装

- HUD・タイトル・一時停止・クリア・失敗画面を日本語化。ゲーム名、キー名、HPと色識別のA/Bは維持し、中ボスの画面上の呼称は「ガーディアン」に統一した。
- 射撃方向のHUD・開始説明・操作案内・キー設定名を「前→上→下」に変更。内部の0°→60°→-60°とキー配置・切替順は維持した。
- 地図の見出し・凡例・撃破数の文字を削除。パネルを240×170pxから320×104pxへ変更し、内側の地図幅を216pxから296pxへ拡大した。縦横比は維持し、現在地・視界枠・発見と撃破の印・地形更新は残した。
- HP変化時、頭上に幅76pxのバーを3秒表示。緑＝現在HP、赤＝今回失った分、灰＝それ以前の不足分。赤は0.35秒待ってから毎秒40HP分ずつ縮む。回復分は0.7秒間明るい緑にする。上部のHP表示も維持した。
- 赤の「-12」・明るい緑の「+20」など、実際に増減した量を頭上左側に表示し、上へ動かして1秒で消す。敵への黄色い数値は従来の右側表示のまま。バーは自機に追従し、一時停止・設定中はバーと数値の時間も止まる。
- `player.heal(amount) -> int` を追加。最大HPまで回復し、実際の増加量を返す。0以下、満タン、死亡済みでは何も起こさない。回復アイテムは追加していない。
- 自機の矩形衝突形状で敵の体との重なりを検索し、異色なら10ダメージ。同色ではダメージも吸収も発生しない。ガーディアンも実際の大きな形状を使う。体の移動用衝突マスクは変えず、押し合いは生じない。色切替予告中は現在の色で判定する。
- 無敵を1.5秒に延長。全身を0.16秒周期で不透明／不透明度0.12へ切り替える。接触・異色弾を防ぎ、同色弾の吸収は無敵判定より先に処理する。落下ダメージは追加していない。
