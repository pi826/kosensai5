# 単一ワールドの洞窟

2026-10-25、Task 4B。操作は `task4a_controls.md`、戦闘の数値と挙動は `phase3_enemies.md`、実装と検証の集計は `task4b_caves.md` を参照。

## 地形と移動

- 12,288×3,072px、32pxグリッドの一つのワールド。開始X=6144、開始の床上面Y=2304。生成は開始・再挑戦だけで、部屋切替・境界ワープ・移動時の再生成はない。
- 岩盤から14〜22空洞を不規則にくり抜く。開始と3つの中ボスの空洞を置いた後、通常の空洞は置き済みの空洞を乱数で1つ選び、その左右（通路が届く128〜960px先、床高の差は距離の半分かつ384px以内）か上下（縦穴が通る288px以上の重なり）に置く。寸法・床高・向きは乱数で選び、空洞間に64px以上の岩を残す。固定の格子は使わない。近い空洞の施工可能な組から木を作って辺を足し、独立閉路3〜8個にする。候補全ては掘らず、接続数1〜2本と3本以上の空洞を混ぜる。外周は64px以上の岩盤。
- 通常空洞は幅640〜1536、高さ320〜704px。床高は各シード8種類以上。上416〜1120、中1152〜2016、下2048〜2944pxの範囲から選び、各地域に2帯以上を含む。開始空洞は幅896px以上、床Y=2304を維持。中ボス空洞は幅1024〜1408、高さ576〜704pxで、位置と帯を地域ごとに変える。通常空洞の50%以上に32〜128pxの段差、30%以上に突起か垂下岩を置く。
- 横通路は長さ128〜1024、高さ160〜256px。異なる床高の空洞も、32px刻み・1段64px以下の坂状の段差で結ぶ。縦穴は重なる水平範囲から位置と幅160〜320pxを選び、足場間隔96〜160px、隣接足場の重なりは自機幅+着地余白以上。空洞内部の薄い足場は1〜4枚で、同じ空洞へ上から入る縦穴を最大1本にし、縦穴の足場も含めて空洞内を1〜4枚にする。
- 縦穴の上端は薄い足場でふさぐ。歩いて渡れ、下からジャンプで出られ、S / ↓ で降りられる。押し続けると重なった足場を順に通過する。
- 初期の1段ジャンプ・歩行・落下・すり抜けだけで、全ての立てる面と全中ボスへ往復できる。接触・落下ダメージはない。移動とジャンプの物理値はTask 4Aから変更していない。

## 到達と配置の保証

- 立てる面を、頭上の岩で分割してから高さごとに併合する。有向辺は垂直ジャンプ、段差へのジャンプ、同じ高さの穴を越すジャンプ、端からの落下、薄い足場からのすり抜け。ジャンプの頭上空間を検査し、落下先は最初に接触する面とする。
- 同じ高さの穴を越すジャンプは、実測した跳躍（`tuning.gd` の `HOP_PROFILES`、ジャンプを押す時間1〜8フレーム）から、12pxの余裕を持って届く最も低いものを選ぶ。その弧の高さまでに薄い足場（落下中に乗ってしまう）や岩（頭が当たる）があれば辺にしない。
- 開始点からの探索と辺を逆向きにした探索で、全ての節点の強連結を確認する。指定面をすべて64px削った地形でも繰り返す。
- 中ボスごとに行き・帰りの `walk / jump / drop / drop_through` 手順を生成する。すり抜けは実際の下入力。実物理走破試験は座標を飛ばさず、この手順を入力として実行する。
- 通常敵40体、7種類を毎シード含み、breaker・flyer・laserの合計45〜60%、1種類30%以下、直線射撃4種類40%以上。空洞ごとに5体以下。開始・中ボスの空洞と開始点から640px以内に通常敵を置かない。通路・縦穴の敵は現在0体。
- 接近点は横の出入口・縦穴の口・床上の通過点。900px以内で岩・薄い足場・ブロックに遮られない攻撃を一つ以上持つ敵だけ採用する。walkerは往復の両端と中央、flyerはレーンの両端と中央も調べる。
- 直線敵は発射口から、laserは既存の `build_curve` の全区間、breakerは既存の1秒の放物線を60分割して検査する。flyerは体・揺れ・余白を含む飛行レーンと、その下のプレイヤー用の隙間も検査する。
- 生成専用の乱数だけを使う。フォールバックは乱数なしの固定配置（`scripts/cave_fallback.gd`）。生成の規則を変えたら `tests/regenerate_cave_fallback.gd` で作り直す。`signature` は全地形・空洞等の接続・保護矩形・削れる面・敵・色・ブロック・手順を含む。

## 壊れる地形と状態

- 削れるのは生成データの `erodible_surfaces` に列挙した、空洞と横通路の厚い床の表面64pxだけ。段差のある通路と、段差・薄い足場へ戻るための踏切面も保護する。開始・中ボスの空洞、出入口の周囲96px、縦穴の最初の足場の下を `protected_rects` で保護する。天井・壁・薄い足場・深い岩盤は削れない。
- 壊れるブロックは10個、2地域以上に分散。32pxグリッド、最大64×64px、耐久3。出入口・往復の歩行区間と踏切・着地・敵の往復範囲・飛行レーンを避ける。ブロック追加後も敵の射線を確認する。
- 床・ブロック・設置壁・砲弾の仕組みと数値は継続。薄い足場は自機・敵の弾・レーザー・砲弾を止める。
- 地域境界で、ワールド・敵のHPとゲージ・予告・弾・砲弾・削れた床・設置壁と残り時間・撃破状態を維持する。再挑戦で全て生成直後へ戻す。
- 同色の攻撃は吸収してゲージ+1、異色はダメージ。発射後の色は固定。通常敵7種類と中ボスの数値、画面外攻撃の禁止は継続する。

## 描画と検証

- 岩盤は行ごとにまとめ、同じ幅の隣接行は上下にも併合する。削れる面とブロックだけ実行時の行衝突で更新する。8近傍接続を維持し、完全に囲まれたセルは単純な塗りつぶしにする。
- 地域背景は空洞の奥に見え、背景・地形の色はx=4096/8192で徐々に変わる。カメラの追従規則は継続。
- ミニマップは探索済みの128pxセルだけを表示し、暗い空間と明るい岩を区別する。破壊と再挑戦でキャッシュを更新する。一時的な設置壁は表示しない。
- Task 4B-4の最終結果は全11テスト・140,615項目・失敗0。1,000シードの生成は平均113.65ms・最大206.98ms、フォールバック0回。`start_run`はシード1 / 37 / 2026で131.32 / 153.09 / 128.96ms、地形の衝突物体は268 / 354 / 295個（敵と自機は別に各44個）。
- 同じ順の往復走破は118.18 / 160.05 / 176.55秒、床を削ったシード37は253.40秒。各テストの項目数、シード別の構成・敵の統計は `task4b_caves.md` に集計した。通常描画37画像を更新し、指定画面を目視確認済み。ログ・JSON・画像は `builds/qa/caves/`。
- 自動走破は戦闘を止めて行う。難易度、見やすさ、戦闘込み5〜10分の所要時間は人による確認が残る。
