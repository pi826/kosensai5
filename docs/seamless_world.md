# 塔と吊り橋の単一ワールド

2026-10-25、第3段階 Task 3b。部屋方式の記録は `phase2.md`、敵と地形変更の規則は `phase3_enemies.md` を参照。

## 構成

- 12,288×3,072px、32pxグリッド。地域はxで3等分し、各地域に3本、計9本の塔を置く。開始X=6144、底の上面y=2304。開始・再挑戦以外の生成、移動中のロード・部屋切替・ワープは行わない。
- 塔の外寸は幅640〜832px、外壁は左右64px。位置は基準から最大±256pxずらし、塔間を256〜1,024pxに制限する。地域境界の左右96pxは橋の通行面として空ける。
- 屋上は中ボスの塔でy=640〜960、他で1120〜1504。各地域の唯一最も高い塔に中ボスを置く。屋上は薄い足場と昇降口、左右224pxの胸壁を持つ。
- 橋の高さを先に選ぶ。置ける高さの組を列挙し、本数を1〜3本の実現可能な範囲から生成専用乱数で選ぶ。偶奇で本数を決めない。同じ塔間の橋は288px以上離し、世界全体で4種類以上の高さ、1本の場所と複数の場所を両方確保し、隣の塔間と高さを重複させない。
- 橋の高さ候補は96px刻み。塔の左右の出入口が近接し過ぎることを防ぐ。橋は厚さ16pxの水平な床で、両端の敷居まで切れ目なくつながる。開口は高さ128px、踊り場は同じ高さで幅160px以上。開口以外の外壁はふさぐ。
- 足場の高さは塔ごとに作る。底から96pxの1段目、接続する全橋、屋上を通り、残りを96・128・160pxで埋める。9本中7本以上は異なる列とし、隣の塔とも同じにしない。
- 足場の幅と横位置を段ごとに抽選する。幅160px以上・内部幅−96px以下、上下の重なり54px以上、落下口96px以上を検証する。生成では重なりを確保する下限と、片側160pxまたは中央寄せの両側96pxの空きを使う。全塔で2種類以上の幅を使う。
- 各塔に外壁から張り出す128×32pxの棚と、幅32〜64px・高さ96〜256pxの縦の内壁を各1個置く。縦の内壁は足場から下がる固体で、下の足場を横へずらして回り込めるようにする。棚と縦壁がつながる場合もある。外壁と同じ石積みで描き、射線を遮る。立てる面の上に76px以上の固体のない空間を残し、出入口や屋上の昇降をふさがない。
- 塔間は橋以外に足場のない谷。谷底は固体だが通常の移動・ジャンプでは到達できない。谷の暗い描画は各塔間で最も低い橋の高さから始め、固定のy座標は使わない。

## 敵・破壊・継続状態

- 通常敵は目標24体、許容20〜30体。turret / walker / shifter / flyer / laser / breaker / builderから抽選し、不足する種類は重複種の支持面を使って補充する。各シードで全7種を置く。
- 橋、踊り場、開始以外の塔の底、中ボスのいない屋上、立てる内壁の候補を生成専用乱数で並べ替える。通常敵の30%以上を橋に、20%以下を塔の底に置く。開始塔の内部と開始地点から640pxの安全範囲を避け、支持・埋まり・往復範囲を検査する。
- flyerは空いた橋レーンだけに配置し、複数配置も認める。橋の上面から176px上、端から48px内側を往復する。体・揺れ・余裕を含むレーンは地形と交差せず、下の薄い足場との間に52px以上を残す。
- builderは薄い橋・踊り場にも壁を置ける。出入口とその左右96pxには置けない。移動・戦闘・壁の寸法・耐久・寿命の数値は変更していない。
- 開始と中ボスの塔以外の底だけ、表面64pxを爆発で削れる。橋・外壁・内壁・屋上・薄い足場・谷底は保護する。最大限削れた底から1段目までは160pxで、通常ジャンプで脱出できる。
- 壊れるブロックは4個以上、目標8個。底・踊り場・橋上の候補を並べ替えて選び、2地域以上に分散する。出入口、敵と往復範囲、飛行レーン、往復手順の踏み切り・着地・歩行区間を避ける。
- 同色吸収・異色ダメージ、発射時の弾色、敵の挙動・HP・ダメージ・スコア、画面外の攻撃禁止・起床待ち・予告、接触・落下ダメージなしを維持する。
- 地域境界では弾・砲弾・敵のHP/ゲージ・撃破・破壊セル・ブロック・壁と残り時間を保持する。再挑戦で地形と耐久を復元し、壁・砲弾・探索・戦闘状態を初期化する。

## 生成と到達検証

- `stage_generator.gd` の塔・橋・足場・内壁・敵・ブロック・経路などをsignatureに含める。同じシードでは再現する。固定フォールバックは明示した選択列を使い、要求シードや乱数に依存しない。
- 固体上面と薄い足場を、固体による頭上空間不足で区切り、同じ高さでつながる区間を歩行ノードにまとめる。上昇は通常ジャンプの高さ以内、重なり54px以上、頂点を含む身体の通路に固体がない場合に結ぶ。
- 落下は身体の端が一部掛かる面も含め、最初に衝突する面を調べる。32・64・96px外へ出る候補について、出発時の横移動で壁を通り抜けず、落下中の横移動も別の面に掛からず、身体幅と着地余裕が収まる場合だけ辺を作る。
- 開始からの到達と逆向きの到達により、各塔の底・全足場・踊り場・屋上・橋・中ボスが強連結で、谷底へ到達できないことを確認する。全ての削れる底が64px低下した状態も検証する。
- BFSから中ボスごとに行きと帰りを別々に作る。手順のwalk / jump / dropを実入力に変換して走破する。帰りは落下も使い、歩行途中のブロックによる不要な上昇を防ぐため、その区間も配置予約に含める。
- ミニマップは実際の地形の探索済み部分だけを表示する。カメラの追従数値は維持する。

## 今回の調整値

- 位置のずれ幅は±64pxから±256pxへ拡大。塔間の距離に幅を持たせるため。地域境界の通行余裕96pxを追加した。
- 橋の抽選上限を2本から3本に変更。縦間隔288px、橋長256〜1,024pxは維持。高さ候補の96px刻みは、左右の出入口と足場の最小間隔を両立するため。
- 足場幅の下限160px、落下口の下限96px、縦内壁の幅32〜64px・高さ96〜256px、橋上の敵の下限30%・底の敵の上限20%を `tuning.gd` に追加した。
- ワールド寸法・開始X・底の高さ・移動速度・ジャンプ・重力・戦闘数値は変更していない。仕様からの意図した逸脱はない。
