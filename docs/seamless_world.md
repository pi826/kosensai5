# 単一ワールドへの変更

2026-10-16。現行の第2段階は、全体をひと続きの地形として探索する方式。
部屋方式だった時点の記録は `phase2.md`、ソースはGitコミット `09bacdd` に保存している。

## 遊びと地形

- 12,288×3,072pxの単一マップを、左右移動とジャンプで探索する。探索中にロード、部屋切り替え、通路キーによるワープを挟まない。
- 翠の水路・紫晶の回廊・灰燼の遺構を左右に配置。境界でも地面はつながり、背景と地形色が徐々に変わる。
- 開始地点は中央の安全な地面。左右の中ボスへは起伏のある床を進み、中央上部の中ボスへは128px間隔の足場を12段登る。
- 初期ジャンプだけで全中ボスへ到達し、開始地点まで戻れる。上段から落ちた先にも連続した床がある。
- 地形のグリッドは32px。上下左右と斜めの8近傍から仮タイルを接続する。薄い足場は下から通過できる。
- シードで床の起伏、足場の位置・幅、通常敵の種類・配置・色が変わる。同じシードと設定なら同じ地形・敵になる。
- 第3段階Task 2では床の表面64pxと床上のブロックを破壊でき、設置敵が約8秒で消える壁を作る。中央登攀路の下と地上中ボスの周囲は保護する。床が最大限削れても隣への最大の上りは128pxで、通常ジャンプの範囲内に収まる。

## カメラと探索地図

- カメラは上下左右へ滑らかに追従する。小さな移動で画面が揺れ続けないよう、追従しない余白を設ける。
- 速い落下では下を先に映し、プレイヤーと着地先を画面内に残す。世界の外側は映さない。
- ミニマップは部屋の箱と接続線から、実際の地形表示へ変更した。プレイヤー周囲384pxを128px単位で探索済みとして記録する。
- ミニマップは実行時の床とブロックを表示し、破壊時にキャッシュを更新する。一時的な設置壁は表示しない。同じシードの再挑戦でも新しい地形のキャッシュへ切り替える。
- 探索済みの範囲だけ地形を描き、現在位置と視界を表示。中ボスは画面内で発見してから菱形、撃破後はチェック印を表示する。
- 目標は3体撃破。地図の探索率100%はクリアの条件にしない。

## 戦闘と状態

- 通常敵はHP2で、異色の通常弾2発で倒れる。同色弾は吸収して誘導弾ゲージを得る。残HPは整数、実ダメージは黄色の数値で表示する。
- 中ボスは各地域に1体、HP80。3体をどの順序で倒してもクリア。途中の通常敵は回避できる。
- 地形・敵・プレイヤーは開始時に一度生成する。地域の境界を越えたときには、位置、速度、飛行中の弾、敵のHP・ゲージ、撃破記録、表示中のエフェクトを初期化しない。
- 壊れた床・壊れたブロック、設置壁と残り時間、飛行中のbreaker砲弾も境界で維持する。その場のセル・衝突・描画だけを更新し、ワールドは再生成しない。一時停止・キー設定中は壁の残り時間と砲弾も止まる。
- 画面外の敵は攻撃しない。画面に入ってから1.1秒待ち、通常攻撃ならさらに0.45秒予告して射撃する。敵の接触ダメージと落下ダメージはない。
- 死亡後は同じマップを最初から再挑戦できる。HP・ゲージ・スコア・時間・探索と発見・全敵の状態を初期化する。
- 再挑戦では床とブロック・耐久を生成直後に完全に戻し、設置壁と砲弾を消す。
- 一時停止とキー設定ではワールドとカメラが止まる。Task 4Aで両手操作へ変更し、version 3未満のキー設定は使わない。現行の操作と検証は `task4a_controls.md`。

## 実装の構造

- `stage_generator.gd` は一つのワールド座標系で地形・敵・地域・到達経路を返す。旧部屋・扉データは生成しない。
- `main.gd` のワールド再生成は開始・再挑戦だけ。移動中は同じシーンを使い、カメラと探索記録を更新する。
- `world_terrain.gd` は壊れない部分を大きな矩形にし、表面とブロック・壁のセルを行ごとに連結して衝突形状を作る。変更した行だけ再構築し、変更セルと8近傍の接続・512px単位の該当描画を更新する。この分割は通行や状態の境界にはならない。生成データの `solids` と `breakables` は書き換えない。
- `world_backdrop.gd` は世界座標で背景を描く。`minimap.gd` は探索済みセルの地形を切り出す。
- 調整値は `tuning.gd`。ジャンプ力や地形寸法を変える際は、生成検証と実物理の走破を再確認する。
