# Task 8A: 効果音・BGM・地域の環境音・音量

2026-10-29。音声素材・取り込み・アドオンを使わず、GDScript で実行時に PCM を合成する。図形で描く結晶と2色の世界に、柔らかいノイズ、低い打撃、ガラスとベルの音を合わせる。音はゲーム状態や生成用の乱数を変更しない。

## 効果音

青Aは高く明るく、橙Bは低く温かい射撃・切替・吸収を使う。shot は一斉射撃1回につき1音、director 専用 RNG で音程±3%。aim は前/上/下で倍率1/1.25/0.8、absorb はゲージに応じた和音、crystal は獲得量に応じた小さな音程差、land は落下速度に応じた音量を使う。

全効果音は mono 32000Hz、曲は mono 22050Hz。効果音は4msの立ち上がりと滑らかな減衰、両端0。窓の重みで直流成分を除き、波形全体の倍率でピークを制限する。サンプル単位の切り詰めはしない。頻出の射撃・UIは少ない倍音、風・衝撃のノイズは一次ローパスを通す。

## 曲と環境音

| ID | 設計 | 長さ |
|---|---|---|
| title | D長調付近、76BPM、パッドとガラスのアルペジオ | 25.263秒 |
| region0 | Eの短三度・ペンタトニック、84BPM、木琴風の撥音・ベース・流れのノイズ | 28.571秒 |
| region1 | Fリディア付近、70BPM、FMベルと持続パッド | 27.429秒 |
| region2 | Aフリギア付近、64BPM、低いパッド・金属的な撥音・残り火のノイズ | 30秒 |
| boss | A短調付近、136BPM、8分のベース・撥音・ノイズ打楽器 | 28.235秒 |

曲はサンプル数を丸めて loop_begin=0 / loop_end=全サンプル数にする。音符のリリースと0.19秒の薄い反響を末尾から先頭へ循環加算する。地域ごとに2種類の単発環境音を作り、その時のカメラ中心の地域だけで3〜9秒間隔、左右・音程を専用 RNG で変えて小さく鳴らす。環境音とジングルは BGM バスを使う。

- タイトル、チュートリアル中と練習完了はタイトル曲。
- 本編の開始・再挑戦は開始地域。カメラ中心の地域が1.5秒続くと3秒のクロスフェード。
- 生存ボスが画面内に0.3秒いると1秒でボス曲。毎回先頭から再生。画面外4秒、または撃破で2.5秒かけて地域へ戻す。
- 一時停止・地図・店・装備・キー設定・音量設定は曲を0.25秒で10dB下げ、復帰時に戻す。
- 失敗・クリアは0.5秒で曲を消し、死亡音／撃破音のあと0.8／1.5秒遅らせて lose／win。その後タイトル曲を9dB下げて戻す。
- 曲は2つの AudioStreamPlayer でクロスフェード。切替途中で元の地域へ戻る場合は再生位置を保って反転し、別の3曲目へ切り替える場合は音量が大きい方のプレーヤーを残して切り替える。未合成の曲は要求を保持し、完成後にフェードインする。

定位は要求元の `view_rect()` に対する横位置を計算し、プールの各 AudioEffectPanner へ渡す。視界外は距離に応じ最大18dB下げ、視界から半画面幅より離れた音は記録だけ残す。再生ノードを host に集約するため、SubViewport の別 World2D / リスナー設定に依存しない。原点移動では保持した発音位置も同量移す。

BGM・SE は Master の下に作り、Master に AudioEffectHardLimiter（天井 -0.5dB）を1つ置く。プールの32個の定位バスも固定名で再利用する。UIは乾いた音。残響は曲の合成に含める。ワールドの効果音は各停止画面で一時停止して再開する。再挑戦・タイトル・練習開始終了では止める。streaming_wait は短時間の繰り返しなので音を止めず、波形の断続を避ける。長い保留ではレーザーの予告音が表示より先に終わる場合があるが、発射音は実際の発射フレームで鳴る。タイトルの裏のワールドからの要求は state 理由で抑止する。

## 音量と保存

全体80・BGM60・効果音80が既定。0〜100%、10%刻み。0はバスの mute、100は0dB、それ以外は `linear_to_db((v/100)^2)`。全体80で約-3.88dB、BGM60で約-8.87dBになる。

タイトル・一時停止・失敗・クリアと練習一時停止から「音量」で開く。「キー設定」と同じ行で幅を揃え、タイトルへ戻るがある場合は3分割。↑↓/Tabで行、←→で10%、Enterでボタン、Escで閉じる。スライダーはマウスでクリック・ドラッグできる。全体・SEの変更で短い確認音。キーイベントはパネルで処理済みにし、ゲームや背後のメニューへ渡さない。閉じると元のメニューと「音量」ボタンへ戻る。

保存は `user://audio.cfg` の `[audio] version=1, master, bgm, se`。閉じる時と既定に戻す時だけ書く。項目ごとの壊れた値は既定、範囲外は丸め、版が違う場合は全て既定に戻す。`main.audio_settings_path` で差し替え可能。専用検査・描画確認は builds/qa/sound/ 内の別ファイルを使い、本物の設定が変わらないことを検査する。

直近512件の要求をリングに保持する。物理フレーム、論理ID・音源ID、位置、音量、音程、pan、発音成否と理由（state / unsynthesized / volume_zero / same_frame / interval / id_limit / voice_limit / offscreen / disabled）を記録する。

## 未確認事項
