# Task 5D：移動するボス・循環・クリア

2026-10-26。5A〜5Cの未コミット変更を維持して追加した。5Eのチュートリアルは対象外。

## 実装

- ガーディアンは空洞内を小さく浮遊して往復し、速さを周期的に変える。初回は生成時の出現点に近い移動範囲を優先し、既存の接近経路から見つけられる位置に置く。ラスボス・裏ボスは体、移動範囲、速度、上下の動きを大きくした。ボスは全身と全移動範囲が岩・薄い足場・箱に重ならない矩形を選び、その中で反射する。物理衝突も使用し、地形は変更しない。画面外では停止し、再び画面に入ると起床待ちから予告する。移動中も攻撃する。
- ガーディアンは既存の色切替と単発／5方向射撃、満タン時の誘導弾を維持。ラスボスは短い間隔の5方向射撃と、型に応じた誘導弾1発を混ぜる。裏ボスはさらに短い7方向射撃＋誘導弾1発。追加ボスは型に応じて扇の向きも揺らす。すべて予告、同色吸収、異色ダメージ、発射後の色保持、接触ダメージを共有する。
- 通常射撃の仕様は Task 9E で変更（[task9e_dynamite_barrage_demo.md](task9e_dynamite_barrage_demo.md)）。本文の単発／5方向／7方向の記述は変更前の記録。
- 初回の3体は従来の `guardian_sectors(seed)` にいる。3体撃破でラスボス、ラスボス撃破で新しいガーディアン3体、これを3巡して裏ボス、裏ボス撃破でクリア。ガーディアンだけではクリアしない。HPは80／160／240。撃破点は1,000／3,000／10,000、誘導弾報酬は2／3／5回分（所持上限5）。ボスだけの合計は13体・28,000点。
- 追加配置は撃破時のプレイヤー区画からチェビシェフ距離2〜5。シード・周回・種別で初期化した専用乱数で候補区画をシャッフルし、既存の幅768px以上・高さ448px以上の通常空洞から、全移動範囲が収まるものを選ぶ。プレイヤー区画と過去の配置も入力なので、同じシード・周回・移動履歴で再現する。復活3体は地域がすべて異なる。初回も含む過去の全ボス区画を除外し、毎回別区画に置く。
- 配置探索は `WorkerThreadPool` 上の専用ジョブで行う。SceneTreeへは触れず、完了後にメインスレッドで記録を追加する。未読込区画にも配置でき、区画完成時に実体を追加する。選んだ空洞の通常敵を除き、その空洞の通常敵の5C復活も抑止する。箱・ハート・地形・ゲートの生成は変更しない。
- 出現時に地域名・方角・区画距離を中央へ6秒表示。復活ガーディアンには復活と周回を表示する。初回ガーディアンは従来どおり発見後、追加・復活ボスは出現時から地図に印を付ける。ラスボスは金、裏ボスは紫の輪付き。範囲外は縁の方向印。HUDは現在の段階と周回・ラスボス回数を示し、近くのボスの名前・整数HPも共通の位置へ表示する。
- `BossCycle` が周回、ラスボス回数、個体ID、場所・HP・生死を区画と独立して保持する。区画解放時は位置、HP、ゲージ、色、速度、攻撃タイマー、移動位相・方向を保存する。生存個体だけ同じ状態で復元し、予告は破棄して起床待ちから再開する。倒した個体は5Cの復活対象にしない。循環による復活は新しいIDの個体。再挑戦では配置ジョブも終了させ、最初の3体だけの進行へ戻す。
- 裏ボス撃破でスコア・時間・ガーディアン／ラスボス／裏ボスの撃破回数を結果へ表示する。自機との同時撃破は通知順にかかわらず失敗を優先し、結果画面は1回だけ開く。
- 5Cで消えた「飛行中の自機誘導弾の追尾先」の照準印を復元した。次の1回分の最大4体との和集合で、画面内の生存追尾先にはストック0でも残る。次の候補から同色敵が外れても、すでに飛んでいる弾の追尾先には印が残る。

最終の実走破は区画 `(-1,2)` → `(4,-1)`、12,281フレーム・125ジャンプ、最大移動量16px／フレーム。途中で64px高い支持面に着地したため1回再探索し、ラスボスの空洞内まで到達した。新規ボス10体のうち9体は出現決定時に区画が未読込で、その後の読み込みと実体の追加も確認した。詳細は `boss_results.json`。

通常描画の `tests/visual_check.gd` はRTX 3060 / OpenGLで終了コード0・失敗0、`builds/qa/bosses/` に10枚を保存して目視した。ガーディアン移動前後、ラスボス出現、地図の範囲外方向印、ラスボス本体、地図内の印、ガーディアン復活、裏ボス出現、本体、クリア結果。採用ログは `visual_randomized.log`。画像のボス進行・経過時間は検証用に制御しており、所要時間の実測ではない。旧5Cの6枚は `-- --rewards`、旧5Bの8枚は `-- --streaming` で引き続き実行できる。

地形生成（`sector_generator.gd`、`stage_generator.gd`、`sector_job.gd`）、プレイヤー、弾、地形物理、ハートの計8ファイルは変更前の固定ソースとSHA-256が一致した。性能検査12項目も失敗0。生成245標本の平均145.71ms・最大1550.92msは既存の平均80ms・最大400ms目標を満たさず、性能改善を達成したとは扱わない。前後の並行実行条件が異なるため速度比較には使わない。

5Cの既存監査JSONと採用ログを照合し、記録された91,602項目・失敗0と一致した。照準印については5Cの説明と実装が一致していたが4Aの仕様から退行していたため、実装・検査・5C文書を訂正した。

## 範囲と未確認

移動方式は空洞内の浮遊往復を採用した。過去の区画は直前のガーディアンだけでなく全ボス分を除外する。地形の変更やワープは追加していない。適切な空洞が有限候補内に見つからない場合は地形や距離条件を緩めず、エラーを表示する。検査したシード・進行では発生していない。

ボスの強さ・難易度、1周の所要時間、人の長時間操作、単独exeへの書き出しは未確認。5Bの遠方座標精度と原点移動未実装、生成性能の目標未達は継続する。今回の並行検査の時間を単独実行の性能比較には使わない。

`CLAUDE.md`、`.claude/`、`docs/claude_codex.md` は編集していない。コミット・プッシュ・公開・デプロイ・別のコーディングエージェントの起動は行っていない。
