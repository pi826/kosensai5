# CHROMA SHIFT

現在は**第2段階の改修版：一続きの探索マップ**です。
[段階実装計画](docs/roadmap_v2.md)と[現行仕様・検証結果](docs/seamless_world.md)を参照してください。

2色を切り替え、同色の弾を吸収して誘導弾に変える2D探索アクションです。
Godot 4.7.2 Standard / GDScript、1280×720、Compatibilityレンダラーで動きます。

## 遊び方

1. `play.cmd` をダブルクリックします。Godot本体は同梱済みです。
2. タイトルで Enter または「このマップで開始」を選びます。シード値を指定できます。
3. ひと続きの地形を左右に進み、足場を登って3地域を探索します。各地域の中ボスをすべて倒すとクリアです。順番は自由で、道中の通常敵は回避できます。

| 既定キー | 操作 |
|---|---|
| ← → または A / D | 左右移動・向き変更 |
| Space | ジャンプ（短押しで低く、長押しで高く） |
| Z（長押し） | 向いている方向へ通常射撃 |
| X | 青 A / 橙 B の切り替え |
| C | 現在のゲージを全消費して誘導弾を発射 |
| Esc | 一時停止・再開 |

**探索中はロードや部屋の切り替えが入りません。** 地域の境界もそのまま歩いて越えられます。中央から左右へ続く地面と、上へ登る足場があります。カメラは上下左右へ滑らかに追従し、速い落下では下を先に映します。

右上のミニマップには探索済みの地形だけが表示されます。白い点が現在地、枠が現在の視界、菱形が発見した中ボス、チェック印が撃破済みです。3地域の背景色は境界で徐々に変わります。

タイトル・一時停止・結果画面の「キー設定」で、各操作に2キーまで割り当てられます。変更は保存され、案内表示も追従します。以前保存したキー設定も引き継ぎます。

- 自分と同色の弾は吸収し、誘導弾ゲージが1増えます。異色の弾はダメージになります。敵も同じルールです。
- 敵に同色の弾を撃ち込むと、満タンで予告付きの誘導弾を放ちます。吸収ではスコアは増えません。
- 敵と中ボスの残HPは整数だけで表示します。減ったHPを黄色のダメージ数値で表示します。
- 通常敵はHP2で、異色の通常弾2発で倒せます。同色の弾は吸収され、HPは減りません。
- 誘導弾は画面内の異色の敵を優先して分散します。発射後に自分の色を変えても、弾の色は変わりません。
- 地域を越えても飛行中の弾、敵のHP・ゲージ、撃破済みの状態を維持します。敵は画面に入ってから待機し、予告して攻撃します。
- 敵との接触や落下によるダメージはありません。足場の下にも床があり、薄い足場は下からジャンプで通過できます。
- 通常敵100点、中ボス1体1,000点です。通貨・装備は第4段階で追加します。
- HPは100の整数ゲージです。通常の敵弾は12、敵の誘導弾は18ダメージ。HP0で終了します。
- 死亡後は同じ地形を最初から再挑戦できます。HP・ゲージ・スコア・時間・探索状況を初期化し、通常敵と中ボスもすべて復活します。

## 編集と調整

`open-editor.cmd` でエディターを開き、F5で実行、F8で停止します。
戦闘・移動・カメラなどの初期値は `scripts/tuning.gd` にあります。
初期マップは12,288×3,072px、地形グリッド32px、中央の登攀路は128px間隔の12段です。二段ジャンプや誘導弾なしで全中ボスまで往復できます。

| ファイル | 内容 |
|---|---|
| scripts/main.gd | 単一ワールド開始・再挑戦、追従カメラ、地図探索、撃破状態、攻撃生成 |
| scripts/stage_generator.gd | 連続した床と上段足場、シード生成、地形と全中ボスへの往復経路の検証 |
| scripts/world_terrain.gd / world_backdrop.gd | 8近傍の仮タイルと衝突、地域ごとの背景 |
| scripts/minimap.gd / interface.gd | 探索済みの地形地図、日本語画面、整数HP表示 |
| scripts/combatant.gd / player.gd / enemy.gd | 共通の色判定、プレイヤー操作、敵の行動と予告 |
| scripts/key_bindings.gd / key_settings_panel.gd | キー設定、旧設定の引継ぎ、保存・設定画面 |
| scripts/projectile.gd / effects.gd | 通常弾・追尾・衝突、ダメージ数値と図形エフェクト |

## 検証

`test.cmd` で生成、戦闘、操作、キー設定、地形タイル、地域境界の連続性、カメラ、実物理の探索走破をまとめて確認します。
1,000シードの再現性と地形、3シードで全ボスへの歩行・ジャンプによる往復、全6通りの撃破順、死亡時の完全リセットを検証しています。

描画検査は次で再実行でき、`builds/qa/seamless/` に各画面を保存します。

```powershell
$env:APPDATA = "$PWD\.userdata"
& .\tools\godot\Godot_v4.7.2-stable_win64_console.exe --path . --fixed-fps 60 --script tests/visual_check.gd
```

戦闘を含む1プレイ5〜10分は調整目標です。人のプレイでの所要時間・難易度確認は残っています。
5種類の移動敵は第3段階、鍵・二段ジャンプ・商人・装備は第4段階、生成画像・音は第5段階で追加します。

ソース・シーン・テスト・文書はGitの `main` ブランチで管理しています。Godot本体、キャッシュ、個人設定、検証画像、旧版ZIPは除外しています。履歴は `git log --oneline`、未記録の変更は `git status` で確認できます。
旧部屋方式はコミット `09bacdd`、その仕様の記録は `docs/phase2.md` に残しています。
プロファイルとログは `.userdata/`、エディター設定は `tools/godot/editor_data/` に保存します。
単独exeへの書き出しは未実施です。現在は同梱Godotで起動する試作です。
