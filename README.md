## 遊び方

`play.cmd` で起動し、シードを指定して「このマップで開始」を選びます。
開始は区画 (0, 0)。空洞・段差のある通路・縦穴が上下左右に続き、探索中の部屋切替・ロード画面・境界ワープはありません。
3体のガーディアンの位置はシードで決まり、別々の地域の区画にいます。撃破順は自由で、3体撃破でクリアです。

| 既定キー | 操作 |
|---|---|
| A / ←、D / → | 左右移動・向き変更 |
| Space / W | ジャンプ。短押しで低く、長押しで高く |
| S / ↓ | 薄い足場をすり抜ける。長押しで次の足場も降りる |
| J（長押し） | 通常射撃 |
| K | 青 A / 橙 B の切り替え |
| L | 射撃方向を 前 → 上 → 下 と切り替え |
| ; | ストックを1回分使い、誘導弾4発を一斉発射 |
| E | 調べる。現在は対象なし |
| Esc | 一時停止・再開 |

「前・上・下」は内部では0°・60°・-60°。向きを変えても仰角は維持します。開始・再挑戦で「前」に戻ります。
タイトル・一時停止・結果画面の「キー設定」で全10操作に2キーまで割り当て、version 3形式で保存します。

- 同色の攻撃を吸収すると吸収メーターが1増え、4回で誘導弾のストックが1回分増えます。ストックは最大5回。上限ではメーターも4で止まり、発射後の次の吸収でストックへ変換します。異色の攻撃でHPが減り、弾は発射時の色を維持します。敵のゲージは従来どおり8で満タンです。
- HPは100。通常敵のHPは2で、異色の通常弾2発で倒せます。敵弾は12、敵の誘導弾は18、異色の体との接触は10ダメージ。被弾後1.5秒は無敵で、無敵中も同色の弾を吸収できます。落下ダメージはありません。
- 通常敵は1区画14体で、固定砲台・地上巡回・色切替・飛行・レーザー・地形破壊・地形設置の7種類。画面外の敵は攻撃しません。画面に入ると待機してから予告します。
- 自機の誘導弾は画面内の生存敵を狙い、異色がいれば異色だけに各敵への本数を均等に割り当てます。対象が倒れると最も狙われていない敵を選び直します。照準印は次の1回分で狙う最大4体に出ます。ストック0では発射しません。
- 指定した厚い床の表面64pxだけを爆発で削れます。開始・ガーディアンの空洞、入口、縦穴、踏切は保護します。天井・壁・深い岩盤・薄い足場は壊れません。
- 壊れるブロックは1区画4個、耐久3。通常弾3発・誘導弾1発、または爆発で壊れます。設置壁は1体2枚までで、約8秒後に消えます。
- HP変化時は頭上に3秒間バーを表示します。緑は残HP、赤は今回失った分、灰は以前からの不足分。回復した分は明るい緑と「+30」等で表示します。敵の残HPとダメージも整数で表示します。
- 通常空洞にはピンクのハートが1区画0〜2個あり、触れるとHPが30回復します。満タンなら残ります。自機の通常弾・誘導弾で箱を壊すとHPが6回復します。敵の爆発・設置壁の破壊では回復しません。
- 通常敵100点と誘導弾1回分、ガーディアン1体1,000点と2回分。消えた通常敵・箱・ハートは45秒後から5秒ごとに25%の確率で元の場所へ戻ります。視界の周囲96pxまでを避け、プレイヤー・設置壁・敵の体と重なる場合は見送ります。削れた床とガーディアンは戻りません。復活した敵からも報酬を得られます。
- 死亡後は同じシードで再挑戦し、全区画の破壊・敵・ハート・復活時刻・探索・ストック・スコアを初期化します。

## 区画・地図・カメラ

内部では世界を4,096×3,072pxの区画に分けます。地形は32pxグリッド。
各区画の中身はシードと整数の区画座標、隣とのゲートはシードと共有する境界だけで決まり、読み込む順番に依存しません。
不規則な4〜8個の空洞、通路・縦穴、段差・突起・垂下岩・足場を組み合わせます。

開始時は周囲8区画も完成させます。移動中は周囲2区画まで別スレッドで先読みし、地形・描画・敵をメインスレッドで分割して追加します。
距離4以上の区画を解放するので、境界を往復しても直ちに読み直しません。
解放後も壊れた床・ブロック、敵の撃破・HP・ゲージ・位置、取ったハートと復活の時刻・試行番号を保存します。解放中も復活時間が進み、再読み込み時に反映します。弾・砲弾・レーザー・設置壁は解放時に消えます。
準備が間に合わない場合は、完成済みの画面でシミュレーションを保留し、未完成の地形への侵入を防ぎます。

カメラに世界の外周制限はありません。地域の名前と配色は区画の地域から決まり、上下の地域境界でも色が滑らかに変わります。
ミニマップはプレイヤー中心の横3区画分を表示し、探索済みのセルだけを描きます。探索記録に固定の地図サイズはありません。
白点が自機、枠が視界、菱形が発見済みガーディアン、チェック印が撃破済み。範囲外の発見済みガーディアンは縁の方向印で示します。文字の凡例はありません。
HUD・一時停止・結果画面は「探索 n区画」、通常敵は撃破数だけを表示します。

生成に人工的な外周は設けていませんが、同梱エンジンの単精度座標には精度の限界があります。遠方の実測と運用目安は [検証報告](docs/task5b_streaming.md) を参照してください。原点移動は実装していません。

## 編集と検証

`open-editor.cmd` で編集し、F5で実行、F8で停止します。調整値は `scripts/tuning.gd` にあります。

| ファイル | 内容 |
|---|---|
| scripts/main.gd | 開始・再挑戦、カメラ、探索、HUD、戦闘の接続 |
| scripts/sector_generator.gd | シードと区画座標からの生成、ゲート・地域・ガーディアン、検証 |
| scripts/sector_job.gd / sector_stream.gd | 別スレッドの生成、座標変換、先読み・解放・状態保存 |
| scripts/streamed_terrain.gd / world_terrain.gd | 分割追加、8近傍接続、衝突、床・ブロック・設置壁 |
| scripts/stage_generator.gd | 到達グラフ、射線、配置、掘り抜きの共通処理 |
| scripts/world_backdrop.gd / minimap.gd / interface.gd | 地域背景、移動する探索地図、日本語画面 |
| scripts/combatant.gd / player.gd / enemy.gd | 色判定、操作、敵の挙動 |
| scripts/heart.gd | ハートの描画・揺れ・取得と回復 |
| scripts/projectile.gd / laser_beam.gd / bomb.gd | 通常弾・誘導弾、レーザー、砲弾 |

`test.cmd` は全自動検査を順番に実行して最後に停止します。個別実行は次の形式です。

```powershell
$env:APPDATA = "$PWD\.userdata"
& .\tools\godot\Godot_v4.7.2-stable_win64_console.exe --headless --path . --fixed-fps 60 --script tests/streaming_test.gd
# 描画確認。画像は builds/qa/rewards/ に保存
& .\tools\godot\Godot_v4.7.2-stable_win64_console.exe --path . --fixed-fps 60 --script tests/visual_check.gd
```

実物理のガーディアン往復、全種類の継ぎ目、先読み・解放、状態保持、遠方、生成・戦闘・操作・キー設定・地図・カメラを検査します。
項目数・報酬と復活の検査は [Task 5C](docs/task5c_rewards.md)、区画読み込みの性能と精度は [Task 5B-2](docs/task5b_streaming.md) に記録します。

5Dのボス移動・追加ボス、5Eのチュートリアルは今回の対象外です。回復量・復活頻度と難易度の釣り合いは未確認です。

Godot本体・キャッシュ・個人設定・検証画像はGitの対象外。プロファイルとログは `.userdata/`、検証ログ・画像は `builds/qa/` に保存します。
