# CHROMA SHIFT

現在は**第3段階 Task 3b：塔・橋・敵配置のばらつきと内壁の修正**です。
[段階実装計画](docs/roadmap_v2.md)と[現行仕様・検証結果](docs/seamless_world.md)を参照してください。
追加した敵の仕様・検証結果は [第3段階の敵](docs/phase3_enemies.md) にあります。

2色を切り替え、同色の弾を吸収して誘導弾に変える2D探索アクションです。
Godot 4.7.2 Standard / GDScript、1280×720、Compatibilityレンダラーで動きます。

## 遊び方

1. `play.cmd` をダブルクリックします。Godot本体は同梱済みです。
2. タイトルで Enter または「このマップで開始」を選びます。シード値を指定できます。
3. ひと続きの地形を左右に進み、足場を登って3地域を探索します。各地域の中ボスをすべて倒すとクリアです。順番は自由で、道中の通常敵は回避できます。

| 既定キー | 操作 |
|---|---|
| ← → または A / D | 左右移動・向き変更 |
| Space | ジャンプ（短押しで低く、長押しで高く） |
| Z（長押し） | 向いている方向へ通常射撃 |
| X | 青 A / 橙 B の切り替え |
| C | 現在のゲージを全消費して誘導弾を発射 |
| Esc | 一時停止・再開 |

**探索中はロードや部屋の切り替えが入りません。** 地域の境界もそのまま歩いて越えられます。9本の塔を、塔間ごとに1〜3本から抽選した吊り橋で結びます。各塔は出入口に合わせた独自の足場列を持ち、段ごとに幅と横位置が変わります。石積みの内壁には張り出す棚と縦に下がる壁があり、回り込んで登り下りします。カメラは上下左右へ滑らかに追従し、速い落下では下を先に映します。

右上のミニマップには探索済みの地形だけが表示されます。白い点が現在地、枠が現在の視界、菱形が発見した中ボス、チェック印が撃破済みです。3地域の背景色は境界で徐々に変わります。

タイトル・一時停止・結果画面の「キー設定」で、各操作に2キーまで割り当てられます。変更は保存され、案内表示も追従します。以前保存したキー設定も引き継ぎます。

- 自分と同色の弾は吸収し、誘導弾ゲージが1増えます。異色の弾はダメージになります。敵も同じルールです。
- 敵に同色の弾を撃ち込むと、満タンで予告付きの誘導弾を放ちます。吸収ではスコアは増えません。
- 敵と中ボスの残HPは整数だけで表示します。減ったHPを黄色のダメージ数値で表示します。
- 通常敵はHP2で、異色の通常弾2発で倒せます。同色の弾は吸収され、HPは減りません。
- 通常敵24体の種類と支持面を生成専用乱数で選び、不足する種類を補います。30%以上を橋、20%以下を塔の底に置きます。開始の塔には置きません。
- 通常敵は固定砲台（turret）、地上巡回（walker）、色切替（shifter）、飛行（flyer）、レーザー（laser）、地形破壊（breaker）、地形設置（builder）の7種類です。飛行敵は橋の上面から176px上を往復し、高いジャンプからの水平射撃で狙えます。真下の足場にもプレイヤーが立てる空間を確保します。
- レーザー敵は地上に固定され、0.6秒の曲線予告後に0.3秒照射します。予告開始時の狙いと色を維持し、地形で止まります。同色なら1本につきゲージ+1、異色なら14ダメージです。
- 地形破壊敵は3.2秒間隔、0.6秒の着弾予告後に砲弾を撃ちます。目標と色を固定し、約1秒で届く放物線を描きます。半径44pxの爆発は同色ならゲージ+1、異色なら16ダメージで、直撃と爆風を重複判定しません。
- 爆発で表面64pxまで削れるのは、開始の塔・中ボスの塔を除く塔の底だけです。橋・外壁・内壁・屋上・谷底は壊れません。底が最大限削れても、初期ジャンプで登って帰れます。
- 床上の壊れるブロックは最大64×64px、耐久3。通常弾3発・誘導弾1発、または爆発で壊れます。敵弾とレーザーは遮り、それらでは壊れません。削れた床と壊れたブロックはミニマップにも反映します。
- 地形設置敵は0.6秒予告して、プレイヤーとの間に幅32px・高さ64〜96pxの壁を設置します。設置間隔は4.5秒、1体につき有効な壁は2枚まで。壁は本体とプレイヤー弾を止め、敵弾・レーザー・砲弾を通します。耐久3で、約8秒後に消え、最後の1.5秒は点滅します。敵を倒しても壁は残り、プレイヤー弾や爆発でも壊せます。
- 誘導弾は画面内の異色の敵を優先して分散します。発射後に自分の色を変えても、弾の色は変わりません。
- 地域を越えても飛行中の弾・砲弾、壊れた地形、設置壁と残り時間、敵のHP・ゲージ、撃破済みの状態を維持します。敵は画面に入ってから待機し、予告して攻撃します。一時停止・キー設定中は壁の時間と砲弾も止まります。
- 敵との接触や落下によるダメージはありません。橋は切れ目がなく、塔の外壁は橋の出入口以外をふさぎ、屋上には胸壁があります。谷底には行けません。塔の内部では足場脇と屋上の昇降口から下りられます。薄い足場は下からジャンプで通過できます。
- 通常敵100点、中ボス1体1,000点です。通貨・装備は第4段階で追加します。
- HPは100の整数ゲージです。通常の敵弾は12、敵の誘導弾は18ダメージ。HP0で終了します。
- 死亡後は同じ地形を最初から再挑戦できます。HP・ゲージ・スコア・時間・探索状況を初期化し、通常敵と中ボスもすべて復活します。床・ブロックを生成直後に戻し、壁・砲弾を消去します。

## 編集と調整

`open-editor.cmd` でエディターを開き、F5で実行、F8で停止します。
戦闘・移動・カメラなどの初期値は `scripts/tuning.gd` にあります。
初期マップは12,288×3,072px、地形グリッド32pxです。塔の位置は基準から最大±256pxずらし、塔間は256〜1,024pxにします。各塔の底から96px上に最初の足場を置き、全出入口と屋上を96〜160px間隔でつなぎます。9本中7本以上で高さの列を変え、隣の塔とも同じにしません。各地域で唯一最も高い塔の屋上に中ボスがいます。二段ジャンプや誘導弾なしで全中ボスまで往復できます。

| ファイル | 内容 |
|---|---|
| scripts/main.gd | 単一ワールド開始・再挑戦、追従カメラ、地図探索、撃破状態、攻撃生成 |
| scripts/stage_generator.gd | 塔・外壁・内壁・吊り橋、シード生成、有向グラフによる往復検証と実入力用の手順生成 |
| scripts/world_terrain.gd / world_backdrop.gd | 8近傍タイル、表面・ブロック・壁の実行時状態と行単位の衝突更新、地域背景 |
| scripts/minimap.gd / interface.gd | 探索済みの地形地図、日本語画面、整数HP表示 |
| scripts/combatant.gd / player.gd / enemy.gd | 共通の色判定、プレイヤー操作、敵の行動と予告 |
| scripts/key_bindings.gd / key_settings_panel.gd | キー設定、旧設定の引継ぎ、保存・設定画面 |
| scripts/projectile.gd / effects.gd | 通常弾・追尾・衝突、ダメージ数値と図形エフェクト |
| scripts/laser_beam.gd | 固定したベジェ曲線の予告・照射、地形遮断、1本につき1回の接触判定 |
| scripts/bomb.gd | 固定目標の予告・着弾印、放物線砲弾、地形破壊と1回だけの色判定 |

## 検証

`test.cmd` で生成、戦闘、操作、キー設定、地形タイル、地域境界の連続性、カメラ、実物理の探索走破、新しい敵、地形変更をまとめて確認します。
1,000シードで再現性・地形・橋の本数と敵構成の統計を検査します。3シードでブロックを残した全ボスへの往復と全橋の双方向通行、シード37の床破壊後の往復、削れた底への下降と通常ジャンプでの脱出、全9塔の登頂・下降、全6通りの撃破順、死亡時の完全リセットも検証します。実行結果は `docs/seamless_world.md`、統計JSON・ログ・画像は `builds/qa/towers/` にあります。

Task 3b の確認結果: 全11テスト・300,464項目・失敗0。1,000シードで3本の橋を含むワールド753件、本数列827種類、敵構成974種類、塔間256〜1,024px。通常描画10枚も更新しました。

戦闘を止めた往復時間はシード1で145.97秒、37で127.42秒、2026で124.80秒、床を広く削った37で127.42秒です。削れた底への下降と160pxの通常ジャンプによる脱出も、別の実物理試験で確認済みです。

描画検査は次で再実行でき、`builds/qa/towers/` に各画面を保存します。

```powershell
$env:APPDATA = "$PWD\.userdata"
& .\tools\godot\Godot_v4.7.2-stable_win64_console.exe --path . --fixed-fps 60 --script tests/visual_check.gd
```

戦闘を含む1プレイ5〜10分は調整目標です。人のプレイでの所要時間・難易度確認は残っています。
第3段階の通常敵7種類と変化する地形を実装済みです。鍵・二段ジャンプ・商人・装備は第4段階、生成画像・音は第5段階で追加します。
