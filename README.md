## 遊び方

`play.cmd` で起動し、シードを指定して「このマップで開始」を選びます。
タイトルでは「同じ色を吸収して、違う色で攻撃せよ！」と大きく表示します。30秒操作がないとラスボス戦のデモに切り替わり、キー・クリック・タッチ・ゲームパッドのいずれかでデモを閉じて、表示中のシードで本編を開始します。
初めて遊ぶ場合は、タイトルの「チュートリアル」を選んで操作を練習できます。マウス、またはTabで選んでEnterで開始します。
固定された一続きの練習場で、移動・ジャンプ・すり抜け・射撃方向・色と吸収・誘導弾・箱とハートの回復・重力反転・ダイナマイト・接触と無敵を順に練習します。
説明は現在のキー設定に追従します。練習中はHPが1未満にならず、一時停止からいつでもタイトルへ戻れます。
完了後は「本編を始める」「タイトルへ戻る」を選べます。本編のシード入力・スコア・時間・進行には影響せず、キー設定を共有します。
開始は区画 (0, 0)。空洞・斜めに上り下りする段床通路・緩い段差通路・横道のある縦穴が続き、探索中の部屋切替・ロード画面・境界ワープはありません。
最初の3体のガーディアンはシードで決まる別々の地域にいます。撃破順は自由です。
3体を倒すとラスボスが出現し、地域名・方角・区画距離を6秒表示します。倒すと別の場所にガーディアン3体が復活します。
この循環でラスボスを3回倒すと裏ボスが出現し、裏ボス撃破でクリアです。結果にはスコア・時間・各ボスの撃破数を表示します。
浮遊する「強化の灯」を1体倒すと、その挑戦の間、今倒すべき最寄りの生きたボスの方角を淡い黄の矢印で自機の周囲に表示します。復活した強化の灯でも解禁できます。他の通常敵やボスの撃破では解禁しません。解禁までは左上に「強化の灯を倒すとボスの方角が分かる」、解禁時に一度だけ通知を出します。
矢印は直線方向を指し、距離の文字は表示しません。未読込の最初のガーディアンは区画の中心を目安にし、読み込まれたら実際の位置へ切り替えます。対象が画面内・出現場所の決定中・クリア後は非表示。再挑戦で解禁状態をリセットし、チュートリアルでは表示しません。

| 既定キー | 操作 |
|---|---|
| A / ←、D / → | 左右移動・向き変更 |
| Space / W | ジャンプ。短押しで低く、長押しで高く |
| W / ↑ を2回 | ジャンプ。0.25秒以内の2回目で発動し、押し続けると高く跳ぶ |
| S / ↓ | 薄い足場をすり抜ける。長押しで次の足場も降りる |
| J（長押し） | 通常射撃 |
| K | 青 / 橙 の切り替え |
| L | 射撃方向を 前 → 上 → 下 と切り替え |
| ; | ストックを1回分使い、誘導弾4発を一斉発射 |
| E | 近くの宝箱を調べる／商人と話す。店では閉じる |
| Q | 回復薬を1個使いHPを40回復。満タンなら使わない |
| Shift | 解禁後、空中ダッシュ。向いている方向へ進む |
| M | 大きな地図を開く・閉じる（チュートリアルでは無効） |
| Esc | 一時停止・再開。大きな地図・店を閉じる |

「前・上・下」は内部では0°・60°・-60°。向きを変えても仰角は維持します。開始・再挑戦で「前」に戻ります。
タイトル・一時停止・結果画面の「キー設定」で全13操作に2キーまで割り当て、version 3形式で保存します。以前の保存にダッシュ・アイテム使用・地図の行がなければ既定値を補います。重複したキーは拒否します。読込時に既定値の補完と既存設定が重複した場合は全操作を既定値へ戻します。

- 敵撃破で「結晶」を得ます。通常敵5、ガーディアン50、ラスボス150、裏ボス300。吸収では増えません。所持数はHUD、獲得合計は結果に表示します。結晶入りの宝箱は30〜80、寄り道の結晶は40です。
- 鍵に触れて拾い、宝箱の近くで「調べる」を押すと鍵を1つ消費します。鍵がなければ開きません。ガーディアンも鍵を1つ落とします。開封・収集は区画を離れても維持し、発見した未収集の鍵・未開封の箱は地図に表示します。能力の箱は紫、通常の箱と鍵は金です。
- 能力の箱は3つ。開始区画で二段ジャンプ、開始からチェビシェフ距離2〜3区画で空中ダッシュ、2〜4区画で滑空を覚えます。3つとも初期能力で到達・帰還できます。開封時の説明は現在のキー設定に追従します。
- 二段ジャンプは空中でジャンプをもう一度押すと発動し、通常の85%の速度で跳びます。短押しで低く、長押しで高くなります。空中ダッシュは空中でShiftを押すと向いている方へ約0.18秒、960px/秒で水平に進み、その間は落下せず、壁で止まります。両方とも着地まで各1回です。
- 滑空は落下中にジャンプを押し続けると落下上限が120px/秒になります。空中で押した際に二段ジャンプが残っていれば先に跳び、そのまま押し続けると下降時に滑空します。解禁後の能力で空洞上部の離れた棚へ寄り道できます。全ゲートと全ボスへの主経路は初期能力だけで往復できます。チュートリアルでは能力を使いません。
- 商人は開始区画に必ず1人、他は約5区画に1人。攻撃しない人物で、初期能力で往復できる空洞の支持面に立ちます。近くで「調べる」を押すと店を開き、ワールドを止めます。発見した商人は地図の緑の家形の印に残ります。
- 店は大小のカードを格子に置く bento layout で、最大7品をスクロールせず表示します。回復薬・鍵は左に上下、装備は右に品数に合わせた大小のカード（7品時は大1枚と小4枚）。枠の色帯と図形で種類を示します。「買う」「装備」はTabまたはボタンで切り替え、↑↓←→でカード間を移動、Enter・Spaceで決定、マウスでクリック、Esc・調べるで閉じます。結晶不足・所持済み・上限・売り切れを各品物に表示します。回復薬は結晶30で最大3個、鍵は120で商人ごとに1個。装備は80〜200で、開始の店は速射の銃身・厚い外殻・誘導の札、他の店は装備3〜5種類を売ります。
- 装備は武器・防具・お守りに各1つ。購入しただけでは付かず、店または一時停止の「装備」で選ぶと効果がすぐ働きます。装備画面は3枠を横に並べ、上の大きなカードに現在の装備、下の小さなカードに他の所持品と「外す」を表示します。何も持たない枠には「まだ持っていません」と表示します。プレイ中はミニマップの下に現在の3枠を常時表示。空き枠に付けられる所持品があれば黄色の名前と、現在の一時停止キーから装備画面へ進む案内を表示し、一時停止の「装備」にも●を付けます。チュートリアルでは非表示です。武器は速射・三連・貫通、防具は最大HP・ダメージ軽減・無敵延長、お守りは誘導弾強化・吸収効率・速度強化。効果と価格の一覧は [Task 6B](docs/task6b_merchant.md) に記載しています。ラスボス撃破ごとに得る強化権1つと結晶で、商人の「強化」から所持装備を1つLv3まで強化でき、HUDと装備画面にレベルを表示します。厚い外殻は最大HPと現在HPを30増やし、外す・別の防具へ替えると両方を30減らします（現在HPは最低1）。同じ装備の選び直しでは変化せず、最低1への補正を除き、付け外しでHPの不足分は変わりません。
- 通常の宝箱は結晶30〜80（50%）、回復薬1個（25%）、未所持の装備1つ（25%）。装備を全て所持、または回復薬が満杯なら結晶40になります。装備は開封時の所持品から候補を除いて選びます。
- 倒れて再挑戦すると、結晶・鍵・全能力・所有装備・装着中の装備・回復薬・商人の売り切れ・開けた箱・拾った鍵を全て初期状態へ戻します。区画の解放・再読み込みと原点移動では保持します。

- 同色の攻撃を吸収すると吸収メーターが1増え、4回で誘導弾のストックが1回分増えます。ストックは最大5回。上限ではメーターも4で止まり、発射後の次の吸収でストックへ変換します。異色の攻撃でHPが減り、弾は発射時の色を維持します。敵のゲージは従来どおり8で満タンです。
- HPは100。周回前の通常敵のHPは2（強化の灯は6）で、強化されていない敵は異色の通常弾2発で倒せます。周回前の敵弾は12、敵の誘導弾は18、異色の体との接触は10ダメージ。被弾後1.5秒は無敵で、無敵中も同色の弾を吸収できます。落下ダメージはありません。
- 通常敵は既存7種類を1区画14体と、強化の灯を0〜1体（開始以外は約60%）配置します。開始区画には強化の灯が必ず1体います。画面外の敵は攻撃しません。画面に入ると待機してから予告します。
- 強化の灯は上下に揺れ、小さな空中の範囲を漂います。自分では弾を撃ちません。画面内にいる間、半径240pxの半透明のフィールドで他の通常敵の攻撃待機時間を0.6倍にし、受けるダメージを半減（切り上げ・最低1）します。強化中の敵には淡い緑の輪が付きます。ボスと他の強化の灯は対象外。倒すとフィールドが消え、通常敵と同じ報酬・復活の規則を使います。
- ラスボスの撃破回数n（0〜3）に応じ、全8種類の通常敵を強化します。HPは2→6→10→14、強化の灯は6→18→30→42。誘導弾4ダメージで通常敵に必要な本数は1→2→3→4発です。与えるダメージは×(1+0.2n)を整数に丸め、攻撃待機時間は÷(1+0.15n)、巡回・飛行速度は×(1+0.1n)。HPの不足分は保ち、解放中の区画にも再読込時に適用します。ボスとチュートリアルは対象外です。
- 敵の数も基準の(1+n)倍、最大4倍（区画の基準が14〜15体なら56〜60体）に増えます。地形を変えず、追加候補を別スレッドで決めて段階的に出します。視界の周囲96pxとプレイヤー・他の体・設置壁を避け、見えている場所には急に出しません。追加敵も撃破・復活・区画の解放と再読込・原点移動で状態を保ち、再挑戦で数と強さを初期化します。周回の通知はボス出現通知と別の位置に4秒表示します。
- 自機の誘導弾は画面内の生存敵を狙い、異色がいれば異色だけに各敵への本数を均等に割り当てます。対象が倒れると最も狙われていない敵を選び直します。照準印は次の1回分で狙う最大4体と、飛行中の自機誘導弾の追尾先の和集合に出ます。ストック0でも飛行中の追尾先には印が残ります。
- ボスは専用アリーナ上部の範囲を浮遊して往復し、移動中も予告して攻撃します。薄い足場は通り抜けます。ガーディアンはHP80・最大90px/秒、ラスボスはHP160・最大140px/秒、裏ボスはHP240・最大175px/秒。大きさ・冠・裏ボスの翼、名前とHP表示で区別します。ラスボスは5方向射撃に誘導弾を混ぜ、裏ボスは7方向＋誘導弾。画面外では攻撃せず、同色吸収・異色ダメージ・接触判定は共通です。
- 追加ボスと復活ガーディアンは、プレイヤーの区画からチェビシェフ距離2〜5の専用アリーナに出ます。候補が足りない場合は8区画まで探します。アリーナは生成時から通常敵・収集物などを置かない部屋です。復活3体は別々の地域・3タイプ各1体で、追加配置は過去のボス区画と異なる場所です。
- 指定した厚い床の表面64pxだけを爆発で削れます。開始・ガーディアンの空洞、入口、縦穴、踏切は保護します。天井・壁・深い岩盤・薄い足場は壊れません。
- 壊れるブロックは1区画4個、耐久3。通常弾3発・誘導弾1発、または爆発で壊れます。設置壁は1体2枚までで、約8秒後に消えます。
- HP変化時は頭上に3秒間バーを表示します。緑は残HP、赤は今回失った分、灰は以前からの不足分。回復した分は明るい緑と「+30」等で表示します。敵の残HPとダメージも整数で表示します。
- 通常空洞にはピンクのハートが1区画0〜2個あり、触れるとHPが30回復します。満タンなら残ります。自機の通常弾・誘導弾で箱を壊すとHPが6回復します。敵の爆発・設置壁の破壊では回復しません。
- 通常敵100点と誘導弾1回分、ガーディアン1,000点と2回分、ラスボス3,000点と3回分、裏ボス10,000点と5回分（ストック上限5）。消えた通常敵・箱・ハートは45秒後から5秒ごとに25%で戻ります。視界の周囲96pxと他の体・設置壁を避けます。削れた床と倒したボス個体は戻りません。ボス循環では新しい個体を別の区画に配置します。
- 死亡後は同じシードで再挑戦し、全区画の破壊・敵・ハート・復活時刻・探索・ストック・スコア・ボスの進行を初期化します。

タイトル・一時停止・結果画面の「音量」で全体・BGM・効果音を0〜100%（10%刻み）で変更できます。↑↓で行、←→で調整、Enterで決定、Escで閉じます。マウスのクリック・ドラッグにも対応し、閉じる時に保存します。青Aは高く鋭く、橙Bは低く太い射撃・吸収・色切替の音を使います。8B合成音源の曲は持続音だけをキックに合わせて下げ、ドラムのアタックを保ちます。ドラム・動くベース・コード進行・4小節ごとのフィルがあり、地域やボスに合わせて滑らかに変わります。環境音は小さく保ち、合成音源は起動後に別スレッドで準備します。

Task 8Dの既定音源は、CC0素材と合成層を事前に重ねた効果音60 IDと、HydroGeneの16bit/SNES風OGG曲5本です（[出典](assets/audio/CREDITS.md)）。環境音6種は合成を維持します。ボス撃破時は実時間でスローと音程を戻し、HUDの下に同心円の波紋を表示します。`-- --sound-set=synth`で全て8B合成へ戻せます。未インポート・欠損素材はIDごとに合成へ戻ります。素材を使うには一度エディターを開くか`--headless --path . --import`を実行してください。試聴は`builds/qa/sound/preview-8d/`、詳細は[Task 8D](docs/task8d_impact_sound.md)を参照してください。`play.cmd`と`play-angle.cmd`では起動時にStandard / Dark / Junkalaの3セットからBGMを選べます（`-- --music-set=dark`など）。

## 区画・地図・カメラ

内部では世界を4,096×3,072pxの区画に分けます。地形は32pxグリッド。
各区画の中身はシードと整数の区画座標、隣とのゲートはシードと共有する境界だけで決まり、読み込む順番に依存しません。
不規則な4〜8個の空洞を斜めにも配置し、20〜50度の段床通路と1段32px以下の緩い段差通路、横通路・縦穴、段差・突起・垂下岩・足場を組み合わせます。初期能力で主経路を往復でき、共有ゲートの決め方は従来どおりです。横道のない縦区間は1,024px以下、上下境界から最初の横道までは各側512px以下を検証します。

開始時は周囲8区画も完成させます。移動中は周囲2区画まで別スレッドで先読みし、地形・敵などをメインスレッドで分割して追加します。地形の再描画は視界とその周囲を先に更新し、画面外を別の待ち行列で進めます。
距離4以上の区画を解放するので、境界を往復しても直ちに読み直しません。
解放後も壊れた床・ブロック、敵の撃破・HP・ゲージ・位置、取ったハートと復活の時刻・試行番号を保存します。解放中も復活時間が進み、再読み込み時に反映します。弾・砲弾・レーザー・設置壁は解放時に消えます。
準備が間に合わない場合は、完成済みの画面でシミュレーションを保留し、未完成の地形への侵入を防ぎます。

カメラに世界の外周制限はありません。地域の名前と配色は区画の地域から決まり、上下の地域境界でも色が滑らかに変わります。
ミニマップはプレイヤー中心の横3区画分を表示し、探索済みのセルだけを描きます。探索記録に固定の地図サイズはありません。
白点が自機、枠が視界、菱形がボス、チェック印が撃破済み。最初のガーディアンは発見後、追加・復活ボスは出現時から位置を表示します。ラスボスは金、裏ボスは紫で輪を付け、範囲外なら縁の方向印を出します。文字の凡例はありません。
大きな地図はMで開閉し、開いている間はワールドと時間を止めます。Escでも閉じます。開いたときは自分が中心で、↑↓←→・WASD・ドラッグで移動、ホイール・+/-で拡大縮小、Spaceで自分へ戻ります。探索した全区画を移動して確認でき、地域色・地形・発見したボスと撃破状態・商人・未取得の鍵と箱、区画境界と凡例を表示します。解放済み区画も表示し、原点移動で位置は変わらず、再挑戦で消えます。右上の小さな地図の範囲と印は従来どおりです。

HUD・一時停止・結果画面は「探索 n区画」、通常敵は撃破数だけを表示します。

生成に人工的な外周は設けていません。自機の相対区画座標の絶対値が2以上になった物理フレームの先頭で、全体を区画寸法の整数倍だけ移動します。物理・描画の座標を原点付近へ戻し、区画座標と区画内座標で保存記録を維持します。旧来の±262,144pxという運用目安は撤回しました。方式と実測は [Task 5F](docs/task5f_origin_shift.md) に記録します。
