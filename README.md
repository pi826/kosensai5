# CHROMA SHIFT

現在は**Task 5A：日本語表示・地図・ジャンプ・HP表示・接触ダメージ**の版です。
[段階実装計画](docs/roadmap_v2.md)と[現行仕様・検証結果](docs/seamless_world.md)を参照してください。
追加した敵の仕様・検証結果は [第3段階の敵](docs/phase3_enemies.md) にあります。
操作の仕様は [Task 4A](docs/task4a_controls.md)、洞窟の実装・検証結果は [Task 4B](docs/task4b_caves.md) にあります。
今回の変更と検証は [Task 5A](docs/task5a_ui_feel.md) にまとめています。

2色を切り替え、同色の弾を吸収して誘導弾に変える2D探索アクションです。
Godot 4.7.2 Standard / GDScript、1280×720、Compatibilityレンダラーで動きます。

## 遊び方

1. `play.cmd` をダブルクリックします。Godot本体は同梱済みです。
2. タイトルで Enter または「このマップで開始」を選びます。シード値を指定できます。
3. 開けた空洞を横通路と縦穴で行き来して3地域を探索します。各地域の中ボスをすべて倒すとクリアです。順番は自由で、道中の通常敵は回避できます。

| 既定キー | 操作 |
|---|---|
| A / ←、D / → | 左右移動・向き変更 |
| Space / W | ジャンプ（短押しで低く、長押しで高く） |
| S / ↓ | 薄い足場をすり抜けて下へ降りる |
| J（長押し） | 現在の方向で通常射撃 |
| K | 青 A / 橙 B の切り替え |
| L | 射撃方向を 前 → 上 → 下 → 前 と切り替え |
| ;（セミコロン） | 現在のゲージを全消費して誘導弾を発射 |
| E | 調べる（探索用。現在は対象なし） |
| Esc | 一時停止・再開 |

**探索中はロードや部屋の切り替えが入りません。** 地域の境界もそのまま歩いて越えられます。14〜22個の空洞を不規則に配置し、近い空洞を段差のある通路と縦穴で結びます。閉路は3〜8個です。縦穴の口には歩いて渡れる薄い足場があり、S / ↓ で入れます。カメラは上下左右へ滑らかに追従し、速い落下では下を先に映します。

右上のミニマップには探索済みの地形だけが表示されます。見出し・凡例・撃破数の文字をなくし、地図を広げました。白い点が現在地、枠が現在の視界、菱形が発見したガーディアン、チェック印が撃破済みです。3地域の背景色は境界で徐々に変わります。

左手で移動・ジャンプ、右手で射撃・色切替・射撃方向切替・誘導弾を操作します。マウス照準は使いません。
「前・上・下」は内部では0°・60°・-60°です。向きを変えても仰角は保ち、銃身とHUDに反映します。開始・再挑戦で「前」に戻り、一時停止・キー設定中は切り替わりません。ゲーム名・キー名・HPを除く案内は日本語です。

ジャンプは最高点をほぼ保ち、上昇と落下をゆっくりにしました。実測は高さ173.02px、滞空0.700秒（Task 4Bは170.07px・0.533秒）。横移動・コヨーテ時間・入力予約は維持しています。

タイトル・一時停止・結果画面の「キー設定」で、全10操作に2キーまで割り当てられます。設定欄はスクロールでき、変更は保存され、案内表示も追従します。保存形式はversion 3です。version 3未満の旧設定は読み込まず、今回の既定値を使います。旧ファイルは、次に設定を変更・保存するまで書き換えません。version 3では壊れた行を既定値に戻し、キーの重複を拒否します。

- 自分と同色の弾は吸収し、誘導弾ゲージが1増えます。異色の弾はダメージになります。敵も同じルールです。
- 敵に同色の弾を撃ち込むと、満タンで予告付きの誘導弾を放ちます。吸収ではスコアは増えません。
- 敵と中ボスの残HPは整数だけで表示します。減ったHPを黄色のダメージ数値で表示します。
- 通常敵はHP2で、異色の通常弾2発で倒せます。同色の弾は吸収され、HPは減りません。
- 通常敵は40体。空洞に5体まで置き、開始・中ボスの空洞には置きません。発射口から接近点への見通しを検査し、breaker・flyer・laserを合計45〜60%、1種類を30%以下にし、直線で撃つ4種類を40%以上残します。種類は固定砲台（turret）、地上巡回（walker）、色切替（shifter）、飛行（flyer）、レーザー（laser）、地形破壊（breaker）、地形設置（builder）の7種類です。飛行敵は選んだ床や足場から176px上を往復し、高いジャンプからの水平射撃で狙えます。真下の足場にもプレイヤーが立てる空間を確保します。
- レーザー敵は地上に固定され、0.6秒の曲線予告後に0.3秒照射します。予告開始時の狙いと色を維持し、地形で止まります。同色なら1本につきゲージ+1、異色なら14ダメージです。
- 地形破壊敵は3.2秒間隔、0.6秒の着弾予告後に砲弾を撃ちます。目標と色を固定し、約1秒で届く放物線を描きます。半径44pxの爆発は同色ならゲージ+1、異色なら16ダメージで、直撃と爆風を重複判定しません。
- 空洞と通路の厚い床は、指定した面だけ爆発で表面64pxまで削れます。開始・中ボスの空洞、出入口の周囲96px、縦穴の下を矩形で保護します。天井・壁・薄い足場・深い岩盤は壊れません。全ての指定面を削っても通常ジャンプで往復できます。
- 床や薄い足場の上に壊れるブロックを10個置きます。最大64×64px、耐久3。通常弾3発・誘導弾1発、または爆発で壊れます。敵弾とレーザーは遮り、それらでは壊れません。削れた床と壊れたブロックはミニマップにも反映します。
- 地形設置敵は0.6秒予告して、プレイヤーとの間に幅32px・高さ64〜96pxの壁を設置します。設置間隔は4.5秒、1体につき有効な壁は2枚まで。壁は本体とプレイヤー弾を止め、敵弾・レーザー・砲弾を通します。耐久3で、約8秒後に消え、最後の1.5秒は点滅します。敵を倒しても壁は残り、プレイヤー弾や爆発でも壊せます。
- 自機の誘導弾は画面内の生存敵を狙います。異色の敵がいれば異色だけ、いなければ同色も候補にし、近い順に1発ずつ巡回して割り当てます。各敵への本数の差は1以内です。狙った敵が倒れた弾は、現在狙われている本数が最少の候補を選び直し、同数なら近い敵を選びます。ゲージがあれば発射予定の敵、発射後は追尾中の敵に白い照準印を表示します。発射後に自分の色を変えても、弾の色は変わりません。敵の誘導弾は従来どおり自機だけを狙います。
- 地域を越えても飛行中の弾・砲弾、壊れた地形、設置壁と残り時間、敵のHP・ゲージ、撃破済みの状態を維持します。敵は画面に入ってから待機し、予告して攻撃します。一時停止・キー設定中は壁の時間と砲弾も止まります。
- 異色の通常敵・ガーディアンの体に触れると10ダメージ。同色の体は無害で、互いにすり抜けます。色切替の予告中は切替前の色で判定します。被弾後1.5秒は点滅し、接触・異色の弾のダメージを防ぎます。同色の弾は無敵中も吸収できます。落下ダメージはありません。
- 足場の下にも床があり、薄い足場は下からジャンプで通過できます。上に立ってS / ↓を押すと真下へ降り、押し続けると次の薄い足場も通過します。厚い床・ブロック・設置壁では何も起きず、すり抜け直後のコヨーテジャンプはできません。薄い足場は自機・敵の弾、レーザー、砲弾を引き続き遮ります。
- 通常敵100点、中ボス1体1,000点です。通貨・装備は第4段階で追加します。
- HPは100の整数ゲージです。通常の敵弾は12、敵の誘導弾は18ダメージ。HP0で終了します。
- HP変化時は頭上に3秒間バーを表示します。緑は残HP、赤は今回失った分（時間で縮小）、灰は以前からの不足分。回復分は明るい緑にし、赤の「-12」や緑の「+20」を上に動かして消します。上部のHP表示も残します。共通関数 `player.heal(amount)` は最大HPまで回復します。回復アイテムは5Cで追加します。
- 死亡後は同じ地形を最初から再挑戦できます。HP・ゲージ・スコア・時間・探索状況を初期化し、通常敵と中ボスもすべて復活します。床・ブロックを生成直後に戻し、壁・砲弾を消去します。

## 編集と調整

`open-editor.cmd` でエディターを開き、F5で実行、F8で停止します。
戦闘・移動・カメラなどの初期値は `scripts/tuning.gd` にあります。
マップは12,288×3,072px、地形グリッド32px、外周は64px以上の岩盤です。空洞の数・位置・床高・幅640〜1536px・高さ320〜704pxをシードで変えます。固定の格子は使わず、床高は8種類以上。通常空洞の50%以上に段差、30%以上に突起か垂下岩があり、足場・敵・ブロックの位置も変わります。候補から木を作って辺を足し、独立閉路3〜8個にします。二段ジャンプや誘導弾なしで全ての立てる面と中ボスへ往復できます。

| ファイル | 内容 |
|---|---|
| scripts/main.gd | 単一ワールド開始・再挑戦、追従カメラ、地図探索、撃破状態、攻撃生成 |
| scripts/stage_generator.gd | 岩盤の掘り抜き、空洞・通路・縦穴、射線、強連結と実行可能な往復手順の検証 |
| scripts/world_terrain.gd / world_backdrop.gd | 8近傍タイル、表面・ブロック・壁の実行時状態と行単位の衝突更新、地域背景 |
| scripts/minimap.gd / interface.gd | 探索済みの地形地図、日本語画面、整数HP表示 |
| scripts/combatant.gd / player.gd / enemy.gd | 共通の色判定、プレイヤー操作、敵の行動と予告 |
| scripts/key_bindings.gd / key_settings_panel.gd | 全10操作のキー設定、version 3の保存・設定画面 |
| scripts/projectile.gd / effects.gd | 通常弾・追尾・衝突、ダメージ数値と図形エフェクト |
| scripts/player_health_display.gd | 自機に追従するHP変化バー、赤の縮小と回復の強調 |
| scripts/laser_beam.gd | 固定したベジェ曲線の予告・照射、地形遮断、1本につき1回の接触判定 |
| scripts/bomb.gd | 固定目標の予告・着弾印、放物線砲弾、地形破壊と1回だけの色判定 |
