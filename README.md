# CHROMA SHIFT

現在は改修の**第2段階（縦探索・3地域・中ボス3体・ミニマップ）**です。
[段階実装計画](docs/roadmap_v2.md)と[第2段階の仕様・検証](docs/phase2.md)を参照してください。

2色を切り替え、同色の弾を吸収して誘導弾に変える2D探索アクションです。
Godot 4.7.2 Standard / GDScript、1280×720、Compatibilityレンダラーで動きます。

## 遊び方

1. `play.cmd` をダブルクリックします。Godot本体は同梱済みです。
2. タイトルで Enter または「このマップで開始」を選びます。シード値を指定できます。
3. 分岐の広間から3地域を探索し、それぞれの奥にいる中ボスを倒します。3体すべての撃破でクリアです。順番は自由で、道中の通常敵は回避できます。

| 既定キー | 操作 |
|---|---|
| ← → または A / D | 左右移動・向き変更 |
| Space | ジャンプ（短押しで低く、長押しで高く） |
| Z（長押し） | 向いている方向へ通常射撃 |
| X | 青 A / 橙 B の切り替え |
| C | 現在のゲージを全消費して誘導弾を発射 |
| E | 近くの矢印の通路から隣の部屋へ移動 |
| Esc | 一時停止・再開 |

上向きの通路へは、3段の足場を登って近づきます。部屋の中でカメラは固定され、通路を使うと隣の部屋へ切り替わります。下向きの通路も床にある矢印から使います。

右上のミニマップには訪問済みの部屋だけが表示されます。白枠が現在地、菱形が発見した中ボス、チェック印が撃破済みです。背景の緑・紫・灰赤で地域を見分けられます。

タイトル・一時停止・結果画面の「キー設定」で、各操作に2キーまで割り当てられます。変更は保存され、案内表示も追従します。旧設定も引き継ぎます。Eが既存の別操作に使われている場合、部屋移動には空いているキーを割り当てます。

- 自分と同色の弾は吸収し、誘導弾ゲージが1増えます。異色の弾はダメージになります。敵も同じルールです。
- 敵に同色の弾を撃ち込むと、満タンで予告付きの誘導弾を放ちます。吸収ではスコアは増えません。
- 敵と中ボスの残HPは整数だけで表示します。減ったHPを黄色のダメージ数値で表示します。
- 誘導弾は画面内の異色の敵を優先して分散します。発射後に色を切り替えても、弾の色は変わりません。
- 敵との接触や落下によるダメージはありません。足場の下にも床があり、薄い足場は下からジャンプで通過できます。
- 通常敵100点、中ボス1体1,000点です。通貨・装備は第4段階で追加します。
- HPは100の整数ゲージです。通常の敵弾は12、敵の誘導弾は18ダメージ。HP0で終了します。
- **死亡後の再挑戦は、同じマップを最初から。** HP・ゲージ・スコア・経過時間・探索状況を初期化し、通常敵と中ボスもすべて復活します。
- 部屋を往復する間は撃破済みの敵や中ボスが復活せず、生存中の敵のHP・ゲージも維持します。部屋移動時は飛んでいる弾を消し、敵は進入後に予告して攻撃します。

## 編集と調整

`open-editor.cmd` でエディターを開き、F5で実行、F8で停止します。
戦闘・移動・地域あたりの部屋数などの初期値は `scripts/tuning.gd` にあります。
初期構成は開始部屋1＋各地域4部屋＝13部屋。部屋は1280×736px、グリッド32px、足場の高低差128pxです。部屋数は地域ごと2〜8で調整できます。

| ファイル | 内容 |
|---|---|
| scripts/main.gd | 部屋移動、固定カメラ、訪問・撃破状態、再挑戦、攻撃生成 |
| scripts/stage_generator.gd | 3地域の部屋グラフ、シード生成、地形・配置・往復経路の検証 |
| scripts/room_terrain.gd / room_backdrop.gd | 8近傍で接続する仮タイル、3地域の仮背景と衝突形状 |
| scripts/minimap.gd / interface.gd | 訪問済みの地図、日本語画面、整数HP表示 |
| scripts/combatant.gd / player.gd / enemy.gd | 共通の色判定、プレイヤー操作、敵の行動と予告 |
| scripts/key_bindings.gd / key_settings_panel.gd | キー設定、旧設定の引継ぎ、保存・設定画面 |
| scripts/projectile.gd / effects.gd | 通常弾・追尾・衝突、ダメージ数値と図形エフェクト |

## 検証

`test.cmd` で生成、戦闘、操作、キー設定、地形タイル、部屋移動、実物理の探索走破をまとめて確認します。
1,000シードの再現性と地形接続、3シードで全通路の往復、全6通りの中ボス撃破順と完全リセットを検証しています。

描画検査は次で再実行でき、`builds/qa/phase2/` にタイトル・3地域・中ボス・ミニマップ・設定・結果画面を保存します。

```powershell
$env:APPDATA = "$PWD\.userdata"
& .\tools\godot\Godot_v4.7.2-stable_win64_console.exe --path . --fixed-fps 60 --script tests/visual_check.gd
```

戦闘を含む1プレイ5〜10分は調整目標です。自動操作による到達確認と実画面の描画は確認済みですが、人のプレイでの所要時間・難易度の確認は残っています。
5種類の移動敵は第3段階、鍵・二段ジャンプ・商人・装備は第4段階、生成画像・音は第5段階で追加します。

過去の仕様・検証は `docs/design.md`、`docs/verification.md`、`docs/phase1.md` に記録しています。変更前のソースは `snapshots/` に保存しています。
プロファイルとログは `.userdata/`、エディター設定は `tools/godot/editor_data/` に保存します。
単独exeへの書き出しは未実施です。現在は同梱Godotで起動する試作です。
